# 医学三维模型缺陷检测、受控修复与结构保护

成员1实现与实验章节，2026-10-16。本文说明本次实际完成的子系统；实验原始数据在 results 目录，参数和结果均可复算。

## 1. 目标与实现范围

系统直接处理已重建的三角表面模型。成员1负责输入合法性与拓扑规范化、缺陷检测定位、选定目标修复、版本与日志、导入/诊断/修复页面，以及 E1/E2 实验。桌面页面可独立运行，也能以 QWidget 注册到成员2的公共主窗口。

优化、误差约束候选搜索、六向 CAD 转换和最终统一报告输出属于成员2，本次提供模型和结果协议以及预检样本，尚未进行两人端到端联调。

### 2.2 合成与特殊结构

生成球体、四面体、开放管段、双闭合分量、共顶点双壳、相交三角片、平移且非对称四面体，共7种参考/特殊模型。开放管段有2个天然开口；双分量样本检验不误删结构；共顶点双壳检验仅靠边度数会漏检的非流形顶点。

损坏脚本支持面邻接 BFS 缺面、同向重复、反向重复、重复索引退化面、实际顶点顺序翻面、附加第三面制造非流形边，以及固定种子的顶点扰动。记录 parent_id/version、原始几何哈希、随机种子、原面/顶点位置及新增面索引。参考网格保留为 NPZ。

数据生成默认种子20261016；合成 E1/E2 使用种子17。重跑保证相同参考和种子产生相同几何及缺陷位置；版本 ID 每次新建，不要求不同运行的整个文件字节哈希相同。

## 3. 导入、合法性与数据表示

MeshAsset 用 float64 顶点与 int64 面索引，数组只读。先检查形状、非空、有限坐标、整数面索引、索引范围及非零尺度，再构建拓扑。非法数据报明确原因，不交给过滤器隐式丢弃。

STL 支持 ASCII 和二进制。二进制根据84+50×面数的完整长度识别，避免 solid 开头的二进制头被误当 ASCII。ASCII 逐 facet 校验语法。读取保留重复面和退化面；STL 中独立的三角顶点按严格相同坐标建立共享连接，不做近邻焊接。raw 顶点、规范网格、原到规范映射分别保存。

PLY/OBJ 通过 Trimesh 关闭 process 读取，场景对象拒绝为单模型输入。NPZ 用无 pickle 的数组与 JSON 元数据保留完整精度。正式交接使用 NPZ；STL 导出为 float32，会受格式精度限制，并附带 JSON 元数据。

## 4. 自主拓扑检测算法

### 4.1 重复与退化面

将面顶点索引排序作为无方向键，识别同向及反向完全重复。退化依据三角面积不大于 max(绝对阈值, 相对阈值×包围盒对角线平方)，默认相对阈值1e-12。输出原 face ID 与中心位置。

重复面会人为抬高边度数，因此同时输出原始边关联统计和排除重复/退化后的拓扑视图。所有拓扑对象仍使用原面索引，便于界面定位和修复选定对象。

### 4.2 边面邻接与边界

每面生成三条无向边，字典记录相邻面和有向遍历符号。关联1面为边界，超过2面为非流形边。边界图中各顶点度数均为2的连通分量提取为简单闭环；其余为链或分叉，禁止简单补洞。

环记录顶点顺序、边、邻接面、周长、包围盒与跨度。默认角色 unknown，只有用户选中时才作为 repair_target；不通过环大小判断它是否为医学缺损。

### 4.3 非流形顶点、方向和分量

对顶点相邻面，仅沿包含该顶点的公共边建立局部连接。多个扇区，或 link 图度数不构成单环/单链，即标记非流形顶点。这可识别两闭合壳体仅共享一个点、但所有边度数均为2的情况。

恰有两个相邻面的边要求两面遍历方向相反，否则记录方向冲突。面分量按共享边连接统计，多个分量默认全部保留。

### 4.4 自交与质量状态

调用 PyMeshLab 的 compute_selection_by_self_intersections_per_face，报告被标记面数量，不把它称为相交对数量。依赖缺失、异常或未请求均为 unverified，face_ids 为 null。

只有去重、退化、非流形和方向检查通过，且自交组件成功执行、未标记面，才标为 verified_open_surface 或 verified_closed_surface。只完成拓扑检查时仍是 diagnosed，不把任务 completed 等同为几何有效。

## 5. 受控修复与结构保护

### 5.1 操作策略

所有策略默认关闭。删除重复/退化面需勾选；非流形候选仅删除用户明确输入的 face ID，不自动选择最大分量或猜测多余器官。法线一致化在两面邻接图上 BFS 传播翻转奇偶性，发生矛盾则拒绝；不根据分量有向体积猜测内外壳。

默认选定补洞用 SVD 投影，检查近共面残差，再用耳切法三角化。默认最多64边、跨度10原坐标单位、最大离面残差为跨度的2%。平面模式对投影自交、共线退化、过大或非共面环明确拒绝。补片遍历与原边界面方向相反，不新增中心点、不移动原顶点。2026-10-23 新增显式实验模式，利用局部二次曲面拟合中心构造凸孔扇形补片，会新增一个中心点并强制自交复检；适用条件与限制见《对照后优化》。

### 5.2 复检与回退

每个候选都重新诊断。未选边界的几何边必须仍存在；明确删面仅授权改变该面的边。默认组件数不变，重复/退化、非流形、方向冲突不得增加；选定补洞必须减少相应环数。如果请求自交复检，则组件不可用或仍标记自交也拒绝。

候选拒绝返回同一输入模型和原 version，保存原因以及已经得到的候选诊断。处理成功生成 parent_version，磁盘保存不可覆盖的 NPZ 快照；VersionStore 支持回退、持久 current 指针和版本变更通知。界面收到新版本后清空旧索引，再绑定新诊断。

## 6. 桌面交互与进程隔离

页面包含单位选择、导入、三维旋转缩放与线框、统计、缺陷列表高亮、清理策略、选环补洞、显式删面、回退和导出。计算在 QProcess 独立 Python 中执行，页面只传 JSON 请求和 NPZ 路径；GUI 主线程不执行拓扑计算或 PyMeshLab 调用。

当前实现单任务运行，120秒超时，可取消。取消/超时、非法文件或工作进程异常均保留已有模型并恢复控件；每个任务目录保存参数、输入归档、哈希/单位、原始/规范/输出模型、结果及日志。宿主可复用 Member1Panel 和 ViewerAdapter，或替换为成员2的统一窗口和调度器。

## 7. 实验与结果

### 7.1 E1 检测正确性

6类人工缺陷分别核对：单孔1环、重复面1、反向重复面1、退化面1、单面翻转3条方向冲突、指定边增加第三面形成1条非流形边。另检验开放管2环、双结构2分量、共点双壳1非流形顶点，共9项，预期与实测一致。

### 7.2 E2 修复与结构保护

8项场景覆盖重复清理、退化清理、法线一致化、指定补洞、保留天然开口、保留双结构、删除指定非流形附加面，以及超过跨度限值拒绝。预期与实测一致。拒绝案例保留输入身份和版本，是通过保护要求，不应计为修复成功。

合成 E1+E2 共17项观察，17项满足预期。详细表见 results/E1_E2/results.csv，报告和前后模型、截图与 repair JSON 同目录保存。

### 7.3 真实形状上的人工缺陷验证

在肝脏、股骨、肾脏分别注入重复、退化、翻面、缺面四类缺陷，共12项。均检测到预定增量，修复后对应指标回到原始值。缺面仅删除单个三角形，人工真值为原始局部面；不能推广为任意大型解剖缺损的修复能力。

医学补洞实验跨度限值25为原坐标单位，单位状态仍 unknown。原始自交检查成功；修复默认仅拓扑复检，修复后质量不能自动继承原始自交已验证状态。所有记录见 results/medical_E1_E2/results.csv 与单项 JSON。

### 7.4 软件验证

自动测试41项全部通过，覆盖合法/非法模型、两种 STL 回读、二进制 solid 头、截断和语法错误、缺陷计数、顶点非流形、可复现性、只读输入、清理与补洞、凹多边形耳切、非共面拒绝、结构保留、候选拒绝、版本快照回退、工作进程和实际自交组件。

GUI 自动验证实际显示 Qt/VTK 窗口，检查异步导入/诊断、选项高亮、修复提交、STL导出回读、回退重绑定、医学模型显示、取消、超时、非法输入保留当前版本。结果与截图见 results/gui_verification。

## 8. 失败分析与当前限制

过大孔洞触发 max_hole_span，候选被拒绝，输入版本仍可导出。非共面或复杂环不适合当前投影耳切算法，应交由后续人工决策或其他补洞方法，不能强行封口。

非流形修复是明确选面的候选处理，不保证任意拓扑可修复。复杂自交目前检测并报告，没有通用自动重建算法。成员1的成功判据是可追溯、受控、能复检与回退，不是对全部输入强行生成“有效模型”。

当前独立测试使用实际 Windows/Python 3.11 环境，尚未完成另一台干净电脑安装、成员2优化/CAD联调或正式演示视频。源码和锁定依赖、操作示例、截图、数据许可与接口文档已经准备，可用于后续共同验收。
