## 1. 准备与记录

先决定接受或放弃自己窗口中的未接受预览；需要保留正式进度时导出项目，再关闭手工使用的工作台。自动GUI脚本会打开自己的窗口、加载样例并关闭自己的窗口，不是生产启动时的自动演示。

所有命令在项目根目录的PowerShell中逐条执行：

```powershell
Set-Location -LiteralPath 'D:\作业\Medical_3D_model'
$env:PYTHONPATH = "$PWD\src"
$stamp = Get-Date -Format 'yyyyMMdd_HHmmss'
$testRoot = Join-Path $PWD "results\acceptance_$stamp"
New-Item -ItemType Directory -Path $testRoot | Out-Null
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe -m medical_mesh probe --out "$testRoot\probe"
```

期望：Python为项目`.venv`中的3.11系列；`pip check`报告无损坏依赖；probe目录包含本次请求和结果。FreeCAD的`configured`只说明找到程序，真实可执行性必须通过第9节验证。

每次记录测试编号、输入文件、源哈希或版本、参数、预期、实测、结论、截图及结果目录。测试结论分为：符合预期、未通过、按设计拒绝、未验证、未执行。拒绝危险输入可以是测试通过，不能写成修复成功。

GUI及旧实验脚本通常写固定的`results/...`目录，重跑会更新同名汇总与截图；需要保留旧证据时，先另存对应目录。本手册创建的`$testRoot`只自动隔离显式传给它的命令，不会改变其他脚本的输出位置。不要先重建`data`，也不要删除原始样本来清理测试环境。

## 5. 检测和修复：固定NPZ样本

每换一个案例先处理完当前预览：接受或放弃。使用NPZ作为固定基准，避免STL焊接或浮点回读改变索引和拓扑。

本次实测基准：

|输入|顶点|三角面|关键预期|
|---|---:|---:|---|
|data/damaged/duplicate.npz|482|961|1重复面|
|data/damaged/reverse_duplicate.npz|482|961|1重复面，顶点顺序反向也应识别|
|data/damaged/degenerate.npz|482|961|1退化面|
|data/damaged/flip.npz|482|960|3条方向冲突边，可能标记4个相关面|
|data/damaged/hole.npz|482|959|1个三边简单闭合边界|
|data/damaged/non_manifold_edge.npz|483|961|1条非流形边，涉及3个面|
|data/damaged/noise.npz|482|960|不一定有拓扑缺陷；噪声用形状误差评价|
|data/reference/open_tube.npz|48|48|2个天然开口边界，1个分量|
|data/reference/two_components.npz|8|8|2个连通分量|

非流形例可能另外出现开放链/分支边界；“简单边界环数0”不等于没有任何边界对象。列表里的边数、顶点数和涉及面数是不同统计量。

### DET-01 重复面

1. 打开duplicate.npz，等待检测结束，记录当前正式版本A。
2. 点击“重复面”，定位并放大；重合面不一定看起来像突出的一片。
3. 只勾选“删除重复面”，点击“生成修复预览”。
4. 预期重复面1→0，面数961→960，正式版本仍为A；能看到待接受结果对象。
5. 先放弃：恢复A及原961面；再生成并接受：正式版本变B、960面。
6. 点击回退：返回A；检测结束后点击重做：恢复同一个B，不重新生成版本。
7. 对reverse_duplicate.npz重复检查，应同样识别并删除冗余面。

### DET-02 退化面

1. 打开degenerate.npz，应报1个退化面。
2. 选中“退化面”，点击定位放大。退化面可能缩为线段或点，不能要求看到有面积的红色三角形；看紫色线段/异常点及说明。
3. 只选“删除退化面”生成预览；预期961→960、退化面1→0。
4. 放弃时原版本保留，接受后才提交。不能把“肉眼看不见面”写成没有缺陷。

### DET-03 方向冲突

1. 打开flip.npz，选“方向冲突”，定位并切换线框。
2. 看共享边遍历箭头与青色法线：相邻一致面沿公共边应反向遍历。仅凭三角形位置看不出翻面。
3. 勾选“法线方向一致化”，生成预览。
4. 预期冲突边3→0，三角面仍960；橙色表示被翻转面。4个标记面不等于4个错误面。
5. 此项验证相邻面一致，不推断多层壳体的医学内外方向。

### DET-04 指定小孔

1. 打开hole.npz，点击边界0，使用定位放大。
2. 黄色轮廓是孔边，不是整个黄色区域都缺失。
3. 边界用途选择“待补孔洞”，点击“标记选中边界”。保持该边界被选中。
4. 使用默认平面方法，最大跨度须不小于此边界显示跨度；默认10足够此样本。
5. 生成预览：预计959→960、简单边界环1→0、新增1面，绿色为新面。
6. 展开底部结果，核对重复、退化、非流形、方向和分量未恶化。
7. 双视图两侧应同时可见并同步观察；能切换处理前后、开关变化高亮。
8. 接受前正式版本不变；接受后边界0、960面。截图留存输入、预览和接受后各一张。

### DET-05 天然开口保护

1. 打开open_tube.npz，应为2个24边开口、48面。
2. 依次选中两个边界，标成“天然开口”并确认标记。
3. 不把它们当作待补孔执行填充。即使执行其他清理，目标仍是保持2个开口、1个分量。
4. 未设置有效修改时，软件可以提示无操作或拒绝；这是正常保护行为，不强行要求它生成新版本。

### DET-06 非流形边

1. 打开non_manifold_edge.npz，选非流形边，确认1条边由3个面共享。
2. 点击“查找删面组合/顶点拆分建议”，等待后台复检。
3. 检查候选数量、预算是否耗尽和结构变化；主动选择通过复检的方案，查看位置，再填入删除编号。
4. 生成预览：检查异常边消除、分量及边界符合目标，再接受。
5. 不凭截图猜面编号，不因预算内没找到就宣称无解。超过50000面不会执行此整模候选搜索，属于受限功能的预期反馈。

### DET-07 非流形顶点与STL回读

打开bowtie_vertex.npz，查找并选择顶点拆分建议，预览后检查两个壳体保留。接受后分别导出NPZ/项目包及STL。NPZ/项目包应保留拆分索引；STL回读可能重新焊接重合坐标，应出现风险提醒而非冒充拓扑保持。需要保持独立壳体时测试`.stlset.zip`，集合中的STL按独立对象使用。

### DET-08 连通分量保护

打开two_components.npz，记录2个分量。进行不需要删除分量的处理后仍应为2，不能为了“看起来干净”只保留最大分量。

### DET-09 自交

打开reference/self_intersection.npz，勾选检测自交并重新检测。执行成功且检测到自交时应有索引及高亮；不可用、超时或失败时必须为未验证，不能显示为0个自交。当前没有通用自动修复自交能力，不把缺少“修好”按钮当作本测试失败。

## 6. 版本、项目包和导出

|编号|操作|通过标准|
|---|---|---|
|VER-01|生成预览但不接受|正式版本、原几何不变，正式导出受保护|
|VER-02|放弃预览|原版本及原指标恢复|
|VER-03|接受→回退→重做|恢复原来的版本ID和几何，不是重新计算近似结果|
|VER-04|回退后接受新分支或打开其他模型|不能重做到不相关旧分支|
|IO-01|导出当前正式NPZ，重新打开|版本、单位元数据和几何保持|
|IO-02|导出`.m3d`，新窗口打开|当前版本及已打包父版本可用，边界用途恢复，可继续回退|
|IO-03|导出STL后重新读取|检查实际回读结果及旁注，不只看保存成功；单位需重新确认|
|IO-04|分壳STL集合|逐壳回读通过；不把多个壳重新合并后焊接当作同一测试|
|IO-05|查看导出反馈条和“打开结果目录”|路径真实存在，错误或拓扑变化有提示|

NPZ/完整项目用于精确交接；二进制STL坐标有float32误差，不能要求坐标逐位相等。导出成功不是医学合格或修复通过。

## 7. 简化、平滑、重划分和评价

### OPT-01 指定面数简化

1. 导入reference/sphere.npz，进入“简化与平滑”。
2. 选择QEM；目标模式“目标三角面数”；设480。检查预计结果提示。
3. 不勾九候选搜索时测试单个480面方案；勾选搜索时按搜索实际方案评价，不能仍要求每个候选都是480面。
4. 点击生成，查看底部表格实际面数、D95、最大采样偏差、结构检查和状态。
5. 正常单方案目标应为480面；是否通过还取决于当前误差阈值。默认阈值偏严格，拒绝可能正确，不要单凭拒绝判算法坏。
6. 为复现已记录的桌面通过路径，可在高级设置使用D95/包围盒对角线0.1、采样最大偏差/对角线0.1、面积变化0.5。它们是宽松的流程测试参数，不是精度推荐值；记录下来，不与默认严格门槛的结果混算。
7. 点击方案，预览、放弃、重新预览并接受；接受前正式版本不变。

### OPT-02 保留百分比

同一960面球，选择50%作为目标。核对实际约480面和实际保留率。若约束导致无法精确达到，保留实际面数，不以输入参数冒充输出。测试20%时记录约192面的目标及实际结果，但不保证任意模型在拓扑保护下都精确命中。

### OPT-03 多候选复核

勾九候选搜索，生成后选择非默认行。区分“待复核”和“可预览”；待复核行点击复核并预览，应对该行结果进行最终至少50000点/方向的独立验证，不能悄悄重算另一候选。失败项可观察和查看原因，不能接受为通过版本。

### OPT-04 平滑

使用damaged/noise.npz，分别测试Laplacian和Taubin，初次迭代5。噪声不一定产生拓扑缺陷，因此看表面形状、面积/尺寸变化及误差，而不只看缺陷数量。两次都从同一个原始输入开始，避免串行平滑后误称同输入比较。Laplacian可能收缩；Taubin减少收缩但仍需验证。开放模型还需确认开口/边界保护。

### OPT-05 重划分

选择均匀重划分，记录目标边长和迭代数；边长使用当前原坐标单位。先测试1—3轮，质量增强最多3轮表面投影。观察三角形分布、面数、形状误差、边界和分量；面数增加不一定失败。不能把质量增强开启当成已经通过最终复核。

### EVA-01 独立误差

以sphere.npz为参考，把已导出的候选NPZ作为对比模型，在“误差与对比”选择文件，每方向50000点。预期生成ASD、D95、采样最大偏差及图；同一个文件与自身比较应近于0，而不是要求随机采样或不同格式浮点结果严格等于0。评价不替换正式网格。

### EVA-02 颜色与对象控制

误差图：紫小黄大，灰色表示该面未采样，不是孔洞；颜色是各面采样均值，统计用原始双向样本。改右侧对象颜色不能覆盖此标量色图。切到“实体颜色”后才使用自定义对象色。隐藏、透明度、切换采样点及视角不能改数值指标。最大采样偏差不是严格Hausdorff上界。

### EVA-03 单位

未知单位不自动当成mm；已知不同单位只对评价副本换算，源文件和正式模型不缩放。未知与已确认单位混合时，应要求明确确认或拒绝，不猜测尺寸。不能拿未知单位下的0.1与毫米条件下的0.1直接比较。

## 8. 复杂补洞与受限非流形专项


## 9. STEP / IGS / STL 六向转换

本机已配置便携FreeCAD。新机器需要时才执行`python scripts/setup_freecad_portable.py`；该命令联网下载较大官方便携包并校验，不能当作离线必做步骤。`configs/freecad.local.json`中的本机路径要存在。

### CAD-01 完整矩阵

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/validate_cad.py --out "$testRoot\cad_matrix" --config configs/freecad.local.json
```

输出目录必须是未存在的新目录，不要提前创建`cad_matrix`。脚本生成平移方盒、球面、开放平面、不对称几何，各跑STL→STEP、STL→IGS、STEP→STL、IGS→STL、STEP→IGS、IGS→STEP，真实写出、新进程两档回读及双向采样，保持原坐标，不做ICP或居中。

期望24/24、8/8、`cm_to_mm=true`、`all_passed=true`且退出码0。8项为未知STL单位、面数预算、未获准实体模式、非法离散参数、同格式、超时、损坏STEP、退化周期IGES。它们是预期拒绝/超时，不是8次成功修复。

## 10. 异常、取消与保护

|编号|测试|预期|
|---|---|---|
|NEG-01|取消导入/保存文件对话框|当前对象和版本保持|
|NEG-02|导入无效/损坏/不支持文件|明确错误，旧模型不丢失|
|NEG-03|没选有效修复操作或没标孔就执行|提示无有效操作/目标，或不修改；不得擅自封孔|
|NEG-04|将孔标为天然开口再试图填充|保留或拒绝，不封堵|
|NEG-05|最大跨度设得小于目标孔跨度|拒绝且保留正式版本|
|NEG-06|严格误差阈值导致所有候选失败|显示原因，不自动降低阈值，不自动接受|
|NEG-07|优化、评价或修复过程中点击取消|返回可操作状态，正式版本不变，取消与成功有区别|
|NEG-08|运行中重复点提交/导出/接受|不能同时修改同一正式版本或导出待接受结果|
|NEG-09|任务超时/自交库不可用|明确失败或未验证，不以0或成功代替|
|NEG-10|无效保存路径/权限不足|导出失败提示，不谎报成功，不改原模型|
|NEG-11|回退后尝试重做到无关分支|拒绝或按钮不可用|

不要故意终止所有Python进程来测试取消。大模型或CAD实际任务更容易点击到取消；若小任务瞬间完成，不能据“没取消到”判取消功能失败。后台取消的已有自动界面验证可另运行`python scripts/verify_merged_workbench.py`。
