# E-3D共有功能交互对照与补齐

本轮检查范围是双方共有的导入、网格修复、简化、平滑、重划分、模型观察、结果评价和导出，不包括E-3D的影像、手术规划及其他专有模块。

对照依据为本机已登录的E-3D Master V24.09当前界面，以及此前同输入实测保留的修复/简化/平滑/重划分参数与预览截图。本轮重新查看了模型管理、对象属性及网格工具栏，没有重复付费导出。截图能确认的入口、已有操作实测和本项目新增设计分别说明，不把未执行的厂商操作写成已验证。

## 对照和实现

|事项|E-3D已观察到的行为或入口|本项目现状及本轮补齐|
|---|---|---|
|操作对象识别|操作面板提示当前模型名称；结果列表含操作前缀|新增当前对象栏，显示正式版本、候选、待接受、仅评价、独立回读等身份|
|保留原模型|简化、平滑、重划分结果在列表中另列|保留正式网格，另列当前结果；接受前不替换，放弃不提交|
|结果命名|列表显示简化比例、光滑后、重划分等名称|结果按简化、平滑、重划分、对比或回读命名；支持修改显示名称，不改源文件名|
|显示开关|模型列表有眼睛入口|新增逐对象勾选显示/隐藏，诊断与变化高亮随所属对象一起隐藏|
|对象颜色|模型列表有颜色列，属性中有颜色选择器|新增颜色列与颜色对话框；正式模型和候选有不同默认色；颜色只影响实体显示|
|透明度|模型列表显示透明度百分比|新增所选对象0—100%不透明度，保留视口整体不透明度控制|
|属性|点数、单元数、面积、体积、包围盒及底栏网格统计|新增原网格点面数、面积、面边均长、尺寸及最小/最大坐标；未知单位明确标注；体积继续只在合格单闭合壳体质量报告中提供|
|运行与结果提示|执行、确定、取消及底栏信息；属性随结果变化|新增非模态反馈条、结果目录入口，区分计算完成、未通过、取消、导出成功和失败；不强制弹窗打断连续处理|
|前后数量|简化、重划分预览底栏显示结果点面数|结果区增加处理前后点面数、实际保留比例和误差指标|
|修复前后观察|修复面板有回退/重做、确定/取消|已有前后切换、接受/放弃；本轮补齐可见双视图与变化开关，修复第二视口零宽度问题|
|回退与重做|相关操作面板有回退/重做按钮|已有正式版本回退，新增重做；只允许恢复当前版本的已保存直接子版本，接受新分支或打开其他模型后清空重做栈|
|候选复核|不据截图推断E-3D内部阈值与复核算法|保留本项目独立结构/误差门禁；新增候选状态配色、悬停原因和中文解释，未验证不显示为通过|
|颜色含义|对象色与操作对象标识可见；没有据此推断其误差色图规则|固定说明：绿新增、红删除、橙翻面、黄边界、紫退化/异常点；误差图另用紫低黄高、灰未采样。修改对象色不覆盖误差标量或诊断色|
|保存与导出|导出列表列出待导出对象和格式；付费确认另行出现|正式版本导出和候选预览保持区分，新增导出成功路径、检查提醒及目录按钮；错误明确提示，禁止把未接受候选当正式版本导出|
|侧栏|边缘箭头及可恢复的面板布局|前轮已完成左右收起、关闭、菜单恢复，本轮保留并验证|

## 设计边界

- 对象列表管理当前正式网格及当前任务的相关结果，不改成E-3D任意多对象装配系统。历史版本继续由版本存储、回退和重做管理；独立文件评价或CAD回读不自动成为正式版本。
- 名称、颜色、显示开关和逐对象透明度为当前窗口的观察设置，不写进网格几何或项目包。不能将显示设置误称为永久修改源文件。
- 面边均长按每个三角面的三条边统计，共享边重复计数；不声称与E-3D底栏的边长统计定义完全相同。面积和包围盒均来自原网格，不使用显示简化网格。
- 所有距离、单位和体积保留原先的验证约束；本轮不扩大自交修复、复杂补洞、ROI或临床有效性的能力声明。不能根据界面一致推断算法一致。
- 未照搬E-3D会改变目标的默认策略，例如删除其他分量、填满天然开口；我们的操作仍要求明确目标并预览确认。

## 实际验证与证据

完整自动回归146项通过，包含真实FreeCAD及新增版本重做分支保护。实际桌面流程验证12项通过，覆盖左右参数/对象分区、底部结果独立收起、侧栏、对象显示/改色/透明度/名称、几何未改变、误差色图不被覆盖、候选复核、接受/放弃、独立评价、导出提示及回退后恢复同一版本。

新版结果页自动切换后，再次进入“格式与导出”可继续下一项转换；六方向真实按钮验证全部通过。最初未返回参数页的验证脚本记录保留在`results/cad_six_directions/gui/interaction_navigation_initial.json`，修正脚本导航后通过，未将其当作六向算法失败。
