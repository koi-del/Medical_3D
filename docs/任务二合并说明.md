# 任务一与任务二合并说明

日期：2026-11-04。

## 启动和流程

双击根目录 `启动医学三维工作台.cmd`，或运行 `.venv\Scripts\python.exe start.py`。原 `启动成员1.cmd` 同样指向统一窗口。打开后为空白工作区，不自动加载样例或运行实验。

1. 全局“打开模型 / 项目”导入模型。在“检查与修复”处理缺陷；接受与放弃位于固定底栏。
2. “简化与平滑”使用当前正式模型，不使用未接受的修复预览。四个步骤属于同一个任务，不再按成员划页。
3. 选择QEM简化、Laplacian/Taubin平滑或重划分，按需启用九候选搜索，点击“生成候选并复核”。简化支持保留百分比和目标面数；重划分支持原表面投影的质量增强。最终复核至少每方向50,000点，使用独立种子。高级面板可设置默认相对D95/最大采样偏差/面积变化阈值0.001/0.003/0.01，仅为课程调试值。
4. 查看候选、相机同步的前后模型、误差色图和窗口内报告。通过算法检查不会提交正式版本。
5. 点击“预览所选优化方案”；其他尚未最终复核的方案会先补做最终复核。后台核对来源、几何哈希、误差、拓扑、自交、边界及分量，在原画布显示预览，由固定底栏接受或放弃。
6. 接受后共享同一正式版本；回退同步恢复各功能的参考。独立文件评价在“误差与对比”，原生网格/项目和CAD适配在“格式与导出”。重新检测不会覆盖已有修复/优化审核记录。

保存候选预览仍是独立行为。任务二NPZ+JSON交接格式和任务一内嵌元数据NPZ均可通过统一导入服务读取；前者会验证侧车几何哈希。

## 实际合并内容

| 部分 | 处理 |

| 优化、评价、CAD、报告、后台任务 | 迁入 `src/medical_mesh/member2`，显式适配模型 |

任务二原有 macOS 启动脚本和机器路径未用于合并版。来源模块清单及哈希在 `results/member2_merge/import_manifest.json`。任务二合成fixture仅用于测试，不在产品入口自动运行。

## CAD运行条件

CAD页支持STL、STEP、IGS六个转换方向及独立回读。本机已配置便携FreeCAD 1.1.4，完成24项实际转换、8项异常处理、单位及六方向桌面操作验证，详见[专项报告](../results/cad_six_directions/专项验证报告.md)。

配置 `configs/freecad.local.json` 的 `executable` 为本机实际 `FreeCADCmd.exe` 路径，`arguments` 为 `["{script}"]`。可参考 `configs/freecad.windows.example.json`。本程序也查找PATH、Program Files和LOCALAPPDATA下的FreeCAD安装。此程序不自动安装外部CAD软件。

STL及参考网格需要明确确认单位；转换使用毫米副本，正式模型不缩放。STL转CAD默认限3000面，超过时需先生成经评价的简化候选。转换检查通过不代表有效实体、医学合格或其他厂商CAD兼容。

## 命令行和复现

```powershell
# 在本项目虚拟环境注册命令入口
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m medical_mesh --help
.\.venv\Scripts\python.exe -m medical_mesh evaluate --input data/reference/sphere.npz --candidate data/reference/sphere.npz --samples 1000
.\.venv\Scripts\python.exe -m medical_mesh optimize --input data/reference/sphere.npz --operation qem --ratio 0.8
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/verify_merged_workbench.py
```

CLI提供gui、probe、evaluate、optimize、convert，无自动演示命令。每次计算保存到新的 `runs` 目录；CLI的 `--out` 要求新的输出目录。CLI的算法通过结果也不会自动改变正式版本。

## 验证与限制

实际Qt/VTK验证记录见 `results/member2_merge/gui_verification.json`：空白手动启动、正式模型交接、优化及50,000点最终复核、报告、统一待审核、人工接受、回退及Windows取消；截图同目录。还迁入了任务二的几何、优化、故障和CAD接口测试，并增加跨模块交接、边界移动、过期版本和错误几何拒绝测试。

本机六向转换已实测，完整回归145项通过、无跳过。已增加复检通过的单闭合壳体围合体积；开放面、多壳体或未验证结果不报告体积，多壳体实体归属和受保护ROI映射仍未实现。若明确声明ROI存在，结构门禁返回未验证。分量对应使用逐面中心的双向最近表面归属，边界对应使用双向顶点/中点到折线距离，均不能替代解剖语义或临床验证。实际E-3D六项优化对照与流程验收见 [优化对照报告](../results/e3d_optimization/优化对照与统一流程报告.md)，CAD比较边界见[专项报告](../results/cad_six_directions/专项验证报告.md)。

任务一原有补洞和复杂非流形算法的适用限制仍保留。最终源码包为根目录 `医学三维模型_合并交付包.zip`，排除虚拟环境、原任务二备份、自动演示模块和重复运行会话。
