# 修复变化与补片质量

更新日期：2026-10-29。本轮落实双视图变化比较与补片几何质量检查，不涉及新的 E-3D 付费操作。

## 查看改动位置

生成修复预览后，默认启用“同步双视图对照”和“显示修复变化”。左侧仍是下拉框选定的当前观察版本，右侧显示另一版本；AFTER 表示修复后未接受候选，BEFORE 表示修复前输入。旋转、缩放时共享同一个相机。需要更大视口时可取消双视图，继续在同一相机位置切换前后。

- 绿色：新增三角面，在修复后模型显示。
- 红色：删除三角面，在修复前模型显示。退化面塌缩为线或点时，使用粗线和端点标记。
- 橙色：翻转顶点顺序的面，在两个版本的对应面上显示。

诊断高亮仍可使用；要单独检查几何变化，可清除诊断选择。接受或放弃预览后，两侧比较与变化标记退出。变化叠加层仅用于显示，不修改模型或导出数据。

点击“定位改动”会将两侧一起定位到变化区域，并使用相同局部裁切范围；裁切外缘不是检测出的缺陷。双视图启用时，“保存当前视图”保存两侧图像，旁注记录是否双视图及是否显示变化面。

变化识别按三角面的实际坐标和方向做多重集合比较，忽略面排列、循环顶点顺序和顶点编号。删除一个重复面不会将所有重合面都标记为删除；方向反转单独记录，不混算为新增和删除。坐标变化的三角面会记为旧面删除、新面新增，不表示已完成表面距离评价。

## 理解补片质量

补洞预览底部显示实际新增面数量、最小角、最大长宽比、接缝处最大法线夹角，以及提示。没有新增面时明确显示不适用；没有可测接缝时不填0。

| 指标 | 定义 | 检查提示 |
|---|---|---|
| 最小角 | 新增三角面所有内角中的最小值 | 小于10度时提醒检查尖角 |
| 最大长宽比 | 最长边 / 最短高，取补片中最大值；等边三角形约1.155 | 大于10时提醒检查瘦长面 |
| 接缝最大法线夹角 | 仅统计一侧为新增面、另一侧为原面且恰由两面共享的边 | 大于60度时提醒检查接缝；不统计补片内部边 |

阈值是人工观察提示，不会因为尖角或锐利接缝就直接判定解剖形状错误，也不自动改变现有接受/拒绝规则。保留实际数据后由使用者判断模型用途；例如原模型本来就可能具有锐边。零面积补片的长宽比记为未定义，并列出退化面编号，避免使用无穷大或伪造数值。

这些指标描述三角面形状与接缝，不是原解剖表面的重建误差，也不能代替自交与拓扑检测。曲面补洞仍保留其原有实验范围限制。
