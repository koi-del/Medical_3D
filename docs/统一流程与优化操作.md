# 统一流程与优化操作

双击根目录“启动医学三维工作台.cmd”。同一个模型、同一套版本记录贯穿整个任务，无自动演示。

## 固定布局

- 顶部：打开、导入单位、检查、回退、历史报告、保存项目/导出网格。
- 流程：检查与修复 → 简化与平滑 → 误差与对比 → 格式与导出。
- 左侧：竖向观察工具与当前操作参数；切换顶部功能后，显示对应修复、简化、评价或导出参数。可收起或关闭，点击功能标签会重新展开参数。
- 中央：固定位置的模型画布，视角、线框、不透明度、恢复全貌、截图；同一模型切换步骤尽量保留相机。
- 右侧：只放模型对象列表、名称/颜色/透明度与原网格属性。侧栏关闭后可从顶部“侧栏”菜单恢复。
- 底部结果区：横向显示前后质量摘要、误差指标、候选表，也可切换完整报告和转换记录。任务完成或生成待接受预览后自动展开；可拖动上边缘改变高度，通过“×”收起，再由顶部“结果与报告”重新展开。
- 底部：预览、处理前后切换、接受/放弃、当前进度及取消；运行记录按需展开。

## 一次正常处理

1. 打开模型。STL单位有依据时在导入前选择，否则保持未知；不根据形状大小猜毫米。
2. 查看检查结果，点击缺陷定位。补洞前标记待补孔与天然开口，按需生成修复预览；检查后接受。
3. 简化选择“保留百分比”或“目标三角面数”，确认预计面数。平滑可选Taubin以减少收缩；Laplacian可能收缩。重划分按原坐标边长设置，质量增强最多3轮表面投影松弛。
4. 点击生成方案。高级默认阈值偏严格，未通过时原模型保留；可以点选失败方案检查误差，再根据用途调整阈值，不能把降低阈值当作提高算法精度。
5. 左右模型使用同一色标：紫色偏差较小、黄色较大。灰色是未采样面，不表示缺损。颜色是每面样本均值；右侧ASD、D95和采样最大偏差使用原始双向距离。
6. 选择方案并点击“预览”。若未做最终复核，会先对这个方案补做独立至少50,000点/方向的复核；不会重新生成另一个候选。固定底栏接受后才替换当前模型，放弃保持原版本。
7. 在“误差与对比”可选择独立文件计算双向偏差。已知单位转换只作用于评价副本，未知单位需要明确确认；评价本身不替换模型。
8. 在“格式与导出”保存当前正式模型或完整项目。分壳集合中的STL须作为独立对象导入，避免重新焊接粘连。CAD适配另需本机FreeCAD、已确认单位及面数预算；当前未检测到FreeCAD时按不可用显示。

修复预览的绿/红/橙表示新增/删除/翻面，误差色图表示采样偏差，两者含义不同。体积只对复检通过的单闭合壳体提供；开放面、多壳体和未验证情况显示不可用。
