## 公共模型

`medical_mesh.core.model.MeshAsset` 包含 float64 `vertices[N,3]`、int64 `faces[M,3]`、asset_id、version、source_file、source_sha256、unit_status、source_unit、unit_to_mm、coordinate_note、preprocessing_record、expected_component_count、expected_open_boundaries、parent_version、processing_parameters。

坐标和面数组使用只读字节后备存储；原始几何不原地修改。`derive()` 生成新 version，保持 asset_id，指向 parent_version。显示副本不参与导出和精度计算。单位比例是元数据：`unit_to_mm=10` 表示原坐标单位为 cm，不能再假设 vertices 已转为 mm。

NPZ 无 pickle，包含 vertices、faces 和 JSON metadata；源文件 SHA256 与几何 hash 分别记录，不能混为同一个哈希。STL 先保存 raw 表示，再精确焊接相同坐标，preprocessing_record 记录原顶点到规范顶点映射；没有近邻容差焊接，也不删除面。

## 可直接运行的函数示例

在项目目录设置 `PYTHONPATH=src` 后：

```python
from medical_mesh import load_mesh, detect_defects, repair_mesh, RepairOptions, save_mesh
from medical_mesh.core.versions import VersionStore

mesh = load_mesh('data/damaged/duplicate.npz')
before = detect_defects(mesh, check_self_intersection=True)
candidate, result = repair_mesh(mesh, RepairOptions(remove_duplicates=True))
assert result.status == 'completed'
store = VersionStore('results/handoff_demo/versions')
store.commit(mesh)
store.commit(candidate, result)
save_mesh(candidate, 'results/handoff_demo/accepted_mesh.npz')
restored = store.rollback()
assert restored.version == mesh.version
```

失败示例：对 `data/damaged/hole.npz` 使用 `RepairOptions(fill_boundary_ids=(999,))`。返回的模型为同一个输入对象，result.status 为 rejected，errors 说明未知边界，output_version 保持输入版本。

优化模块调用 `detect_defects(candidate)` 后比较 metrics 中边界、连通分量、非流形等字段，并单独检查 self_intersection 状态。边界 ID 与面索引只对当前 version 有效；版本更新后必须重新检测、清空旧高亮。

## 返回值

所有结果共用 status、input_version、output_version、metrics、warnings、errors、elapsed_seconds、output_paths、quality_status。status 为 completed/rejected/failed/cancelled；任务成功不代表模型质量已验证。

DiagnosisResult 增加 defects、boundaries、components、self_intersection。重复/退化面给原索引和中心；非流形边给端点、相邻面和位置；非流形顶点给位置、扇区数；方向冲突给边与两面。组件为原 face ID 列表。boundaries 中角色默认 unknown，边界不自动称为缺损。

metrics 的顶层拓扑指标基于去重、排除退化面的候选视图；`raw_topology` 提供未去重统计用于解释重复面的影响。`self_intersection.face_ids=null` 表示未验证，`[]` 仅用于组件成功执行且未标记面的结果。

RepairResult 增加 diagnosis_before、diagnosis_after、operations、accepted。repair_mesh 返回 `(MeshAsset, RepairResult)`；仅 accepted 为 true 时采用新模型。拒绝和异常返回输入版本，已经产生的候选复检信息仍保留。

## 独立工作进程

请求示例：

```json
{
  "operation": "repair",
  "run_id": "member2_example",
  "input_path": "data/damaged/duplicate.npz",
  "output_dir": "results/member2_example",
  "parameters": {"remove_duplicates": true}
}
```

保存为 request.json 后，用参数列表启动 `python -m medical_mesh.processing.mesh_worker request.json`，工作目录设项目根，PYTHONPATH 设 src。completed 退出0，其余退出2。进程输出 result.json、原输入归档、raw/canonical/output NPZ、input_metadata.json、request.json、worker.log；修复另有前后诊断 JSON。run_id 由调用方生成；output_dir 由调用方指定并保证每个任务独立。

取消/超时由宿主终止进程并写 cancelled/failed 状态；未写出 result.json 不能按成功处理。当前页面提供120秒超时、单进程运行与错误恢复。成员2统一调度器可以替换页面 start_job，保留函数接口和请求协议。
