# 对照后的实现与验证

更新日期：2026-10-23。此轮改进基于已完成的 E-3D 对照发现；新功能没有再次进行 E-3D 付费实测，不据此宣称超越对方。

2026-10-29 后续扩展：新增双面组合删除与断开面扇区顶点拆分、1—48候选预算、项目包往返与大模型交互。下文为初轮范围记录，当前能力与限制以 [后续优化与大模型验证](后续优化与大模型验证.md) 为准。

## 已实现

- 点击诊断项默认自动定位局部，可关闭自动定位或恢复全貌。黄色表示边，紫色表示退化线段/异常点，方向冲突保留边遍历与法线箭头。
- 边界用途有“待判断”“天然开口”“待补孔洞”。只有标记为待补的简单环才进入 GUI 补洞请求；天然开口禁止补洞，也不能被删面操作破坏。未指定的闭环保留。非闭合缺陷链不当作孔洞，只能在用户明确选择的删面方案中改变；如果将其标记为天然开口，同样强制保护。
- 标记按模型身份及边界坐标保存，而非依赖临时边界编号；重新编号不会串到另一条边界，其他模型也不会继承。会话保存 boundary_roles.json；导出附带版本、几何哈希和用途旁注。
- 非流形边建议在独立工作进程中逐个尝试单面删除，进行拓扑、自交、分量和边界保护复检；只展示通过的方案。最多检查12个候选，超过50000面暂不运行。无适用方案时保留原模型；尚未实现自动拆分顶点或组合删面搜索。
- 多个合法候选都展示，优先排列不新增孔洞、删除面积较小的方案；不自动选中、不直接提交。本次示例面960的删除可恢复闭合球面，但删除面689也能形成合法的开放曲面，说明拓扑合法不能代替用途判断。
- 新增实验局部二次曲面补洞：显式选择后，利用一环邻域在局部坐标中拟合二次曲面，以拟合中心构造扇形补片。保留原顶点、原边界位置；新增一个中心点。要求6—64边、严格凸且投影不自交的简单环，拟合矩阵满秩且条件数不大于10^6，邻域拟合最大残差不超过孔洞跨度3%，中心离面偏移不超过跨度50%，补片三角形最小角不小于5度。强制实际自交复检，失败返回原输入。

## 如何试用

启动方式仍为“启动成员1.cmd”。旧窗口需关闭后重新启动才能加载改动。

1. 补洞：导入 data/damaged/hole.npz，选边界、标记为待补孔洞，再生成预览。仅点击边界不再授权补洞。
2. 天然开口：导入 data/reference/open_tube.npz，将两个环标记为天然开口；其用途保存在会话中。
3. 非流形：导入 data/damaged/non_manifold_edge.npz，查找建议，选择一个方案查看变化，再生成预览。建议不会自动接受。
4. 曲面：运行 scripts/run_optimization_checks.py 后导入 results/optimization_checks/quadric_nonplanar_hole_input.npz。选择跨度较小的内孔并标记为待补，使用实验二次曲面模式；外圈保留。此文件是解析合成曲面，不是患者数据。

## 验证

自动测试64项通过；新增实际 Qt/VTK 验证6项通过，证据在 results/guided_repair_verification。覆盖自动定位、用途持久化、标记后预览与放弃、建议歧义及不自动提交、显式接受、曲面模式强制自交检查与外边界保留。

扩展实验在 results/optimization_checks，包含非共面解析曲面、默认平面拒绝、天然开口拒绝封口、不稳定邻域拒绝、大小不等的双分量，以及约1.6万面的混合缺陷。记录本机处理时间，但没有可比较的 E-3D 计时，不能推断速度优劣。

本轮未验证复杂凹孔、多层/高曲率组织的原形恢复、任意非流形结构自动修复或临床有效性。局部拟合中心误差不是整个补片的表面精度；扇形补片仍是分片平面，不等于光滑曲面重建。原先8案例对照结论只适用于当时的输入和相应策略。
