本阶段已经实现并实际测试：在一个Qt主窗口内完成输入选择、格式转换、后台回读、几何评价、模型对比和报告阅读。运行时使用已安装的FreeCAD 1.1.4命令行环境，不需要手工操作FreeCAD窗口。

## 1. 启动与最短操作路径

双击工程目录中的`启动医学网格工作台.command`。也可以在工程目录执行：

```bash
./启动医学网格工作台.command
```

1. 左侧切换至“CAD转换”。
2. 输入来源选“外部文件”，点击“选择文件…”。支持`.stl`、`.step/.stp`、`.igs/.iges`。
3. 选择输出格式。界面只提供与输入不同的两种格式，合计六个方向。
4. 输入为STL时，必须确认其单位为mm、cm或m。单位未知时，转换按钮不可用；更换文件后需要重新确认。CAD文件按照文件内单位交由FreeCAD读取。
5. 选择任务保存目录。每次任务自动创建带时间和随机编号的新子目录。
6. 通常保持每方向50,000点和整项300秒超时，点击“转换并回读验证”。
7. 在右侧“转换结果”查看写出、回读、几何三种状态和详细检查；在“模型对比”旋转、缩放和比较输入参考与独立回读模型；在“任务报告”阅读HTML或完整JSON。
8. “窗口内查看报告”直接切换本窗口报告页，不启动外部浏览器。“打开已有任务 / 报告”可选择已有任务的`result.json`或`report.html`，再次查看结果与保存的模型。

STL本身不保存长度单位，单位必须根据数据来源确认。例如13cm应转换为130mm，不能把数值13直接标为13mm。

## 2. 输入也可以来自优化流程

1. 在窗口顶部载入网格或合成球面，在“优化”页生成候选并复核。
2. 候选表中选中要转换的候选。
3. 在“CAD转换”页把输入来源切换为“所选优化候选（预览）”。也可以选择“当前参考网格”。
4. 确认面数及单位后，选择STEP或IGS并运行。

程序先保存带版本与哈希的NPZ/JSON快照，后台将坐标一次换算为mm并导出STL，再交给CAD运行器。来源的`asset_id`、`version_id`、`geometry_sha256`、单位倍率、生命周期及质量状态进入结果记录。正式参考网格保持不变。

优化候选的`candidate_unaccepted / unverified`状态不会因为CAD几何检查通过而被提升为正式合格。STL转CAD默认限制为3,000面；更高面数必须先明确生成经过评价的简化副本。程序不做未告知用户的自动简化。

## 3. 六个方向与检查含义

| 输入 | 输出 | 回读对象与参考 |
|---|---|---|
| STL | STEP | STEP独立回读；对照已换算为mm的原始STL |
| STL | IGS | IGS独立回读；对照已换算为mm的原始STL |
| STEP | STL | STL独立回读；对照源STEP的细离散参考 |
| STEP | IGS | IGS独立回读；对照源STEP的细离散参考 |
| IGS | STL | STL独立回读；对照源IGS的细离散参考 |
| IGS | STEP | STEP独立回读；对照源IGS的细离散参考 |

界面分别呈现以下状态：

- **文件写出**：目标文件存在且非空，记录SHA256；仅这一项成功不代表回读或几何一致性成功。
- **回读**：使用独立FreeCAD进程重新加载目标文件并生成评价网格，记录实际表示、有效性、进程编号及包围盒。
- **几何检查**：双向点到三角表面距离、坐标尺寸差、两档离散稳定性和进程独立性全部满足配置时才显示通过。

默认课程验收阈值为D95≤0.1mm、采样最大偏差≤0.3mm、包围盒最大差≤0.1mm、两档离散误差差≤0.02mm。它们是本项目可复现实验配置，不能直接作为临床精度要求。ASD供查看，不额外设置通过阈值。

两档回读分别采用0.01mm/0.1rad与0.02mm/0.15rad参数；源CAD参考采用0.005mm/0.075rad。详见每次报告中的实际`config`。

## 4. 后台执行与异常行为

主窗口使用Qt `QProcess`启动独立Python任务；CAD内核在FreeCAD自身进程运行，主UI不加载其Python库。窗口通过真实阶段消息显示准备、写出、细档回读、粗档回读、源参考、评价和报告保存；执行过程中仍能阅读日志、切换右侧页签和取消任务。

同一窗口只允许一个活动任务，执行期间禁止重新载入参考模型或提交另一任务。每次开始清除上一项转换的结果与预览，避免失败后继续显示上一项的成功模型。

- 非法/缺失输入和未知STL单位：界面先阻止提交；后台仍有二次校验。
- 损坏CAD：显示失败，保留日志与失败报告，后续检查保留为未执行。
- 取消或整项超时：终止本次POSIX进程组，结果标记取消/超时，不能保留“几何通过”的最终状态。之后可继续运行新任务。
- FreeCAD单次调用默认120秒上限；整项超时由界面控制，默认300秒。
- 报告写入失败：后台管理器仍解除忙碌状态，并显示写入错误，不把不可写目录误当作任务成功。

当前进程树清理已在本机macOS测试，Windows仍需单独适配与验证。

## 5. 保存的文件

每个新任务目录至少保存启动请求、执行请求、进程日志和最终报告；具体成功产物包括：

| 文件 | 用途 |
|---|---|
| `converted.stl/step/igs` | 实际转换结果 |
| `result.json` | 窗口及报告读取的统一最终记录，含运行环境 |
| `conversion_result.json` | CAD转换器的详细结果；资产来源见统一结果中的`source_asset` |
| `report.html`、`results.csv` | 可独立查看/导出的报告和指标 |
| `reference_readback.npz/.json` | 评价所使用的参考网格与单位/版本/哈希 |
| `candidate_readback.npz/.json` | 目标文件独立回读的细档网格 |
| `conversion_samples.npz` | 完整采样坐标与距离数组 |
| `error.png` | 固定共同色标的双向误差图 |
| `export_*`、`readback_*`、`source_*` | FreeCAD请求、结果与日志 |
| `source_snapshot.npz/.json` | 从窗口参考/候选转换时的原始来源快照 |

为了保持交互流畅，三维视图每方向最多绘制5,000个采样点；评价和磁盘保存仍使用完整50,000点，不以显示降采样替代计算。

重开任务时需保留整个任务目录。当前记录保存绝对产物路径，若手工移动目录，HTML/JSON仍可阅读，但模型预览可能因原路径失效而不可用；界面会记录具体错误。
