## 1. 选题定位与研究问题

### 1.1 项目做什么

系统接收已经重建好的医学三角表面模型，完成「读取—诊断—修复—优化—评价—格式转换—报告」的完整流程。典型输入包括骨、肺、肝、肾模型，也包括用于验证算法的人工几何模型。

本项目直接处理三维表面网格，不把 DICOM 导入、影像分割或 AI 训练作为前置开发任务。医学背景体现在解剖形状保持、天然开口保护、多连通结构保留，以及处理结果的可追溯性。

流程完整意味着每一步都有输入、输出、参数、检查和失败处理；不意味着所有任意损坏的网格都能自动恢复成真实解剖结构。

### 1.2 主要研究问题

**问题一：能否准确发现常见几何和拓扑缺陷，并对定义范围内的缺陷进行可追溯修复？**

重点研究重复面、退化面、边界环、法线方向不一致、非流形边与非流形顶点。复杂自交必须能够检测或明确报告检测不可用，不能忽略后宣称模型有效。

**问题二：在限制表面变化的前提下，能减少多少三角面、文件大小和后续处理时间？**

重点比较固定参数与受误差约束的参数选择。检验简化、平滑、重划分是否造成局部细节丢失、体积变化或新的缺陷。

**问题三：格式转换后的模型是否保持了约定的几何信息？**

验证六条有向转换路径的文件可读性、几何实体类型、坐标与尺寸、离散后表面偏差。将「导出成功」「回读成功」「几何检查通过」分开记录。

### 2.3 必须明确的边界

1. **重叠的两种情况分开处理。**完全重复、包括反向重复的三角面可以清理；不同三角面之间的几何交叉或重叠属于自交问题，必须单独检测。复杂自交只提供受控候选修复与失败报告，不宣称普遍成功。
2. **边界不自动等于缺损。**血管、气道、截取模型及手术切割模型可能本来就有开口。默认保留边界，用户选择或缺陷生成记录明确指定后才补洞。
3. **多个连通分量不自动等于噪声。**左右肺、多个骨块等可能是正确结构。默认保留所有分量；删除分量须记录用户指定对象。
4. **STL 转 CAD 的必做实现是面片/壳体转换。**满足条件时构造有效实体。自动恢复 NURBS、草图特征、建模历史不属于本课设。
5. **IGES 结果可能是曲面集合。**不能因为能打开就标为有效实体。结果报告必须包含实际实体类型与有效性检查。
6. **制造与 FEA 适配采用明确验证。**模型可读取或可生成表面网格，不等于已经具备制造精度、材料属性或有效有限元计算条件。
7. **本课设提供几何处理研究结果。**没有通过影像、专家解剖标注或实物检测验证的补洞区域，不宣称恢复了真实解剖。

### 2.4 初始规模与执行约束

建议以普通 16 GB 内存电脑为设计起点，不要求 GPU。初始主实验使用约 1 万–10 万个三角面的网格；CAD 面片转换先在 1 千–3 千面模型上验证。以上是控制范围的起始设置，首周根据实测调整并写入配置。

超过容量上限时，系统提示先生成受误差约束的低面数副本，或者拒绝 CAD 转换。不能自动覆盖原模型，也不能为了导出成功而隐藏过度简化。

## 3. 技术路线与开源资源汇总

### 3.1 推荐主技术栈

使用 Python 桌面应用，避免同时开发网站、服务端账户和数据库。核心是 NumPy 数组；GUI、网格处理和 CAD 转换三个运行边界分开。

- GUI：PySide6 + PyVista + PyVistaQt。
- 数值与拓扑：NumPy，自主邻接算法；SciPy 用于必要的稀疏计算与统计。
- 网格读写、基础统计：Trimesh。
- 修复与优化：PyMeshLab。
- 距离评价与显示：VTK/PyVista，优先采用点到三角表面的查询。
- CAD 转换：独立安装的 FreeCAD，通过它自己的运行环境执行任务。
- 报告：标准库 JSON/CSV，Matplotlib 图表，HTML 模板。
- 测试：pytest；重点验证真实缺陷、单位、坐标、回读和失败回退。

### 3.3 项目级复用建议

**PyMeshLab：主算法库。**从官方 README、过滤器列表和 examples/tests 学习接口。对每个调用建立一个适配函数，不让 GUI 直接调用库。过滤器名称和参数以锁定版本为准。[过滤器文档](https://pymeshlab.readthedocs.io/en/latest/filter_list.html)

**PyVista/PyVistaQt：展示基础。**参考 QtInteractor 与网格显示示例，自己完成双视图、同步相机、边界高亮、参数面板和任务状态。[Qt 集成文档](https://docs.pyvista.org/api/plotting/qt_plotting.html)

### 4.3 内部网格表示

统一用顶点 V[N,3]（float64）和三角面 F[M,3]（整数）。为避免过度架构，先不实现复杂半边对象；邻接关系用排序数组、字典或稀疏表表示。

每个 MeshAsset 至少包含：

~~~text
asset_id, source_file, source_sha256, vertices, faces
unit_status, source_unit, unit_to_mm
coordinate_note, preprocessing_record
expected_component_count, expected_open_boundaries
parent_version, processing_parameters
~~~

关键规则：

- 非有限坐标、越界索引先拒绝，不进入过滤器。
- 计算时保留模型原来的空间位置与比例。
- 若使用内部归一化，保存逆变换，输出前恢复。
- 单位未知时只显示原坐标单位和归一化误差；用户确认后才显示 mm。
- 输入对象不可变；处理结果生成新版本。
- 清理、合并或重划分后面索引会变化，不能继续使用原面索引高亮。

worker.log
~~~

不要求每个任务产生所有文件。没有执行的步骤写「未执行」，失败步骤保存异常和现有结果。任务状态建议为 queued、running、completed、rejected、failed、cancelled。

质量状态另外保存：diagnosed、partially_repaired、verified_open_surface、verified_closed_surface、unverified。任务运行结束不等于模型通过质量检查。

### 4.5 进程组织

PyMeshLab、CAD 转换和大规模评价采用独立子进程。主应用传入 JSON 请求文件和 NPZ 网格文件；工作进程写入结果与状态文件。使用 subprocess 的参数列表，不拼接 shell 字符串，不使用 shell=True。

GUI 主线程不能运行耗时计算。通过 Qt 定时轮询或信号更新进度，收到取消请求时终止对应工作进程；CAD 超时保留前一步的网格。先做单任务队列，避免多个库同时修改同一内存对象。

## 5. 实验数据准备及缺陷构造

### 5.1 数据来源与采集顺序

首周先获取 3 个可用模型并验证格式，再扩展样本。候选医学数据源是 [MedShapeNet 官方项目](https://mml.ikim.nrw/ait/projects/medshapenet/) 与 [配套代码仓库](https://github.com/Jianningli/medshapenet-feedback)。官方提供浏览与下载入口，但本方案没有下载或逐模型核实许可。

建议组成：

| 数据组 | 建议数量 | 作用 |
|---|---:|---|
| 自生成几何模型 | 6 个 | 精确控制缺陷与尺寸；球、立方体、圆柱、环面、双分量模型、开放管段 |
| 医学模型 | 12 个起步，最多扩展到 20 个 | 骨、肝、肺、肾等形状上的外部有效性 |
| 天然开口/多分量样本 | 至少 3 个，可与上述重合 | 检验误补洞和误删分量 |
| CAD 模型 | 4 个自生成模型 | 解析几何与六方向转换验证 |

医学数据不必四科均等凑数。如果某类数据来源或许可不清，先使用已确认的其他解剖模型，并在报告说明覆盖范围。不能以下载失败为理由伪造病例或模型来源。

### 5.2 数据清单

manifest.csv 建议字段：

~~~text
asset_id, source_url, source_dataset, anatomy, license_note,
download_date, sha256, source_format, unit_status,
vertex_count, face_count, expected_components,
open_boundary_note, reference_qualification, subset
~~~

reference_qualification 表示是否适合某类实验：closed_valid、open_valid、complex_unverified 等。没有通过检查的原模型不能直接作为「干净参考」。

相同个体或同一模型的不同版本使用同一 group_id。参数开发集与最终评价集按原始模型分组，不按损坏副本随机划分，避免同源泄漏。可以预先指定约三分之一模型用于参数调试，其余用于最终评价；这不是 AI 训练集划分。

### 5.3 STL 连接关系处理

STL 常以三角面顶点重复出现的形式保存。若直接按原顶点编号统计，每个三角面都可能看起来独立。

因此保留两个表示：

1. 原始三角数据：用于存档、输入合法性和原文件检查。
2. 拓扑分析表示：按明确规则建立相同坐标顶点的连接；保存映射与合并数量。

第一版只做严格相同坐标合并，不进行任意近邻焊接。浮点容差焊接作为显式参数，记录最大移动与合并范围。多个表面在同一点接触时可能被误连，必须暴露诊断结果。使用 OBJ/PLY 保存可控的非流形实验样本，避免 STL 的顶点重复改变人为缺陷定义。

### 5.4 缺陷构造方法

| 缺陷 | 构造方法 | 已知答案与记录 |
|---|---|---|
| 局部小孔 | 选择种子面，在面邻接图中 BFS 删除一个紧凑片区 | 删除面、边界环、原始局部参考 |
| 重复面 | 添加既有面副本；另做反向重复变体 | 原面与新增副本的对应关系 |
| 退化面 | 添加重复顶点索引面或共线三角形 | 预期退化面数量 |
| 方向不一致 | 对局部相邻面交换两个顶点的顺序 | 翻转区域；不能仅改显示法线 |
| 顶点扰动 | 用固定种子添加法向/三维噪声 | 噪声幅度、随机种子、参考模型 |
| 非流形边 | 在指定边上增加第三个有效三角面 | 指定非流形边，新增面 |
| 非流形顶点 | 两个面片只共享一个顶点，邻域扇区不连通 | 指定顶点与扇区数 |
| 自交样本 | 生成两个几何相交而非正常邻接的三角面/片区 | 已知相交区域；与重复面分开 |

对缺面样本检查边界是否形成简单环。分叉或多个相连缺口归入复杂样本，不混入简单孔洞的成功率分母。

轻、中、重缺陷强度按模型尺度或原面数定义。具体强度在调试集先验证后冻结；不要随机删掉大量散乱面来代替真实小孔。

### 5.5 样本规模与可复现性

建议最终保留 12 个医学参考模型，每个构造三类主要缺陷、两个强度，形成 72 个损坏实例；再加入解析几何和特殊拓扑单元样本。一个损坏实例不是一个独立患者。

所有派生样本保存 seed、parent_id、损坏区域、生成参数和版本。种子固定且非零。评价时按原模型汇总，报告模型之间的差异，不能把大量同源变体当成独立样本夸大统计结果。

## 6. 缺陷检测算法

### 6.1 重复面与退化面

对每个三角面顶点编号排序，排序后的三元组作为无方向键；相同键为完全重复面候选。用坐标焊接后的顶点编号判断，避免不同编号但相同位置漏检。

三角形面积：

\[
A_f=\frac12\|(v_1-v_0)\times(v_2-v_0)\|.
\]

重复顶点、共线三点或面积小于尺度相关阈值时标为退化。阈值以包围盒对角线 D 的平方归一化，并单独保留绝对阈值配置。近重复面和不同面的局部重叠不能用这一规则解决。

重复面可能干扰边度数，因此输出「原始缺陷统计」和「去重候选后的拓扑统计」两个视图，明确解释差异。

### 6.2 边—面邻接

每个三角面贡献三个无向边，对端点排序后计数：

- 关联 1 个面：边界边。
- 关联 2 个面：局部边关联正常，还要检查方向及顶点邻域。
- 关联超过 2 个面：非流形边。
- 含重复顶点的退化面先单独标记，不用于正常拓扑结论。

面索引、边端点、关联面列表都要保存，便于定位和后续 BFS。

### 6.3 边界环与天然开口

把边界边组成图。每个边界顶点度数恰为 2 的连通边界分量，才作为简单闭环候选；存在度数 1 或大于 2 的节点时，标为开放链或分叉结构，暂不自动补孔。

对每个环统计：

- 边数、周长、包围盒、最大跨度。
- 邻接面、平均局部边长、局部法向。
- 用户指定角色：natural_opening、repair_target、unknown。

环很小也不能自动证明它是错误缺损。自动实验仅对缺陷生成记录标定的 repair_target 执行；真实模型由界面选择目标环。

### 6.4 非流形顶点

仅检查边度数不够：两个闭合表面共用一个顶点时，每条边仍可能恰有两个关联面。

对顶点 v 的 incident faces 构造局部邻接图，仅当面之间共享含 v 的边时连接。多个不连通扇区表明可能存在非流形顶点。进一步检查顶点的 link 是否为一个环或一条链。不能把边度数正常的模型直接称为流形。

### 6.5 面方向与闭合性

对有两个关联面的边，检查两面遍历该边的方向是否相反。使用 BFS 传播面方向，出现矛盾时报告不可定向或数据异常。

闭合网格至少要满足：无边界、无非流形边/顶点、面方向一致、无重复/退化面，以及经过自交检查。若自交检查未执行，只能报告「边界拓扑检查通过，自交未验证」。

闭合、可定向、无自交的单分量才可用有向体积判断整体朝向。多层壳体、内腔与多个嵌套壳不能仅按每个分量体积为正来重定向。

### 6.6 自交检查

使用 PyMeshLab 的 self-intersection selection 或备选 Open3D 检查，输出被选中的面。相邻三角面共享合法边/顶点的接触不应当作普通自交；重复面在前一步单独处理。

检测函数返回的面数不是相交对数量，报告中写「被标记自交面数」。检查失败、超时或算法不支持时，不以零代替结果。

### 6.7 最小自主检测示例

下列示例用于已校验坐标和索引、已建立共享顶点的三角网格。它演示边统计，不包含完整顶点流形、方向与自交检查。

~~~python
import numpy as np

def edge_diagnosis(vertices, faces):
    vertices = np.asarray(vertices, dtype=np.float64)
    faces = np.asarray(faces, dtype=np.int64)
    if faces.ndim != 2 or faces.shape[1] != 3:
        raise ValueError("faces must have shape (M, 3)")
    if len(faces) == 0:
        raise ValueError("empty mesh")
    if not np.isfinite(vertices).all():
        raise ValueError("non-finite coordinates")
    if faces.min() < 0 or faces.max() >= len(vertices):
        raise ValueError("invalid face index")

    repeated = ((faces[:, 0] == faces[:, 1]) |
                (faces[:, 1] == faces[:, 2]) |
                (faces[:, 2] == faces[:, 0]))
    tri = vertices[faces]
    double_area = np.linalg.norm(
        np.cross(tri[:, 1] - tri[:, 0], tri[:, 2] - tri[:, 0]), axis=1)
    scale = np.linalg.norm(np.ptp(vertices, axis=0))
    if scale == 0:
        raise ValueError("zero-scale mesh")
    degenerate = repeated | (double_area <= 1e-12 * scale**2)
    valid = faces[~degenerate]
    edges = np.concatenate((valid[:, [0, 1]],
                            valid[:, [1, 2]],
                            valid[:, [2, 0]]), axis=0)
    edges = np.sort(edges, axis=1)
    unique_edges, degree = np.unique(edges, axis=0, return_counts=True)
    return {
        "degenerate_face_ids": np.flatnonzero(degenerate),
        "boundary_edges": unique_edges[degree == 1],
        "non_manifold_edges": unique_edges[degree > 2],
        "edge_degree": degree,
    }
~~~

本文检测示例已在当前可用 NumPy 环境中通过四项合成检查：闭合四面体、删除一面形成的三边环、退化面、单条非流形边。此验证不涵盖完整软件、GUI、第三方修复或 CAD 转换。

这里的面积阈值是演示参数。正式实现还需处理重复面、保留原始索引映射，并为每种合成样本核对预期结果。


## 7. 模型修复算法与处理策略

### 7.1 标准修复流程

~~~text
输入检查与存档
→ 建立连接关系
→ 原始诊断
→ 在副本上清理重复/退化面
→ 检查法线及非流形结构
→ 必要的非流形候选修复
→ 重新识别边界
→ 对指定目标环补孔
→ 可选局部平滑
→ 完整复检
→ 接受、部分接受或回退
~~~

每次改变拓扑后都重建邻接及索引映射。不能一直沿用修复前的边界 ID 或面 ID。

### 7.2 重复面、退化面与孤立顶点

先移除完全重复面，再处理退化面，最后清理未被引用的顶点。输出移除的数量与原始对象映射。

不默认使用大容差合并邻近顶点；两个很近的表面可能属于不同组织或薄壁结构。若启用近邻焊接，要求用户指定容差，测量位移并复检是否出现新非流形连接。

### 7.3 法线修复

在可定向连通区域中用邻接传播统一绕向。随后仅对满足条件的闭合组件判定整体内外。开放曲面只保证局部方向一致，不声称法线向外。

建议将这一步独立成可观察操作：显示翻转面比例、异常区域及整体方向状态。法线正确会改善显示，但「看起来正常」不能替代拓扑检查。

### 7.4 小孔填补

采用 PyMeshLab 小孔过滤器，并增加自己的目标筛选和复检：

1. 提取简单边界环，排除天然开口、未知边界和分叉结构。
2. 根据用户指定环或合成缺陷记录确定补洞目标。
3. 检查环边数、跨度与局部网格尺度，超过上限时拒绝自动填补。
4. 将目标环相邻面设置为选择区域，调用选择区域补洞。
5. 保存新增面区域并重新识别剩余边界。
6. 检查新增退化、方向、非流形和自交问题。
7. 测量非补洞区域的变化。合成样本还需与未损坏参考模型比较局部补洞误差。
8. 复检失败则回退，保留候选结果用于分析。

PyMeshLab 的 maxholesize 指的是边界边数量，不是毫米直径；本系统另加物理/归一化跨度限制。其防自交选项是算法启发式，不能当作形式化无自交证明。正式结果仍需要复检。[补孔接口](https://pymeshlab.readthedocs.io/en/latest/filter_list.html#meshing-close-holes)

为了避免误封住相邻天然开口，不能仅设置「补所有小于 30 条边的孔」。必须传递目标面选择，操作后检查实际关闭了哪些环。

### 7.5 非流形修复

两种候选策略分别试验：

- **分裂顶点/边：**将异常连接拆开，尽量保留原几何，但可能形成新的边界。
- **删除冲突面：**删除部分关联面，能消除边度数异常，但可能损失局部表面并产生孔洞。

对所有候选都记录：移除面数、新增顶点、连通分量数、边界环数、几何偏差。只因非流形边数归零，不能宣布修复完成。

推荐默认尝试拆分，并对新增边界标为 repair_generated，而非 natural_opening。需要闭合时再进行受控补孔。对无法在误差和拓扑要求内完成的输入返回 partially_repaired。

库中删除面/拆分策略的接口已由官方文档核对。[非流形处理接口](https://pymeshlab.readthedocs.io/en/latest/filter_list.html#meshing-repair-non-manifold-edges)

### 7.6 自交与整体修复

复杂自交不作为自主实现的新算法。先做好检测、定位和拒绝 CAD 实体转换。可选在单个、预期闭合的模型上使用 PyMeshFix 形成对照候选，评价其几何变化。

禁止默认「只保留最大分量」或强制「所有模型都变成单个闭合物体」。开放管段、多骨块等样本必须展示对原有结构的保护。

### 7.7 修复结果状态

| 状态 | 条件 | 后续允许操作 |
|---|---|---|
| verified_closed_surface | 目标缺陷修复；闭合、方向与非流形检查通过；自交已检查 | 网格优化；尝试实体转换 |
| verified_open_surface | 预期开放结构保留；其他要求通过 | 保边界优化；曲面/壳体输出 |
| partially_repaired | 部分缺陷减少，但仍有残留问题 | 查看、继续处理、导出并附报告 |
| unverified | 检查失败或某关键检查未执行 | 不标为合格；提供原始/候选结果 |
| rejected | 候选新增严重问题或超出改变范围 | 保留原模型，记录拒绝原因 |

修复验收分「缺陷消除」与「几何改变」两类。真实缺损没有未损坏参考时，只能报告补洞假设、未修改区域变化和几何检查，不能计算所谓真实恢复准确率。

## 8. 网格优化及误差约束策略

### 8.1 QEM 简化

QEM 将顶点附近三角面的平面距离组合为二次误差，按代价执行边折叠。对平面 p=[a,b,c,d]，令 K=p p^T；顶点累计 Q 为邻近平面的 K 之和，候选齐次坐标 x 的代价为 x^T Q x。

课设调用成熟 QEM 实现，不从零开发全部边折叠数据结构。需要自己解释其代价、边界保护和失效情形。参考原论文与作者资料：[Garland & Heckbert, 1997](https://www.cs.cmu.edu/~garland/quadrics/)。

候选面数保留率起始为 80%、50%、30%；保留率是输出面数/原面数，不是削减率。使用实际输出面数计算结果，不假设一定达到目标。

优先启用边界、法线和拓扑保护参数，但这些是算法约束或启发式，不替代输出复检。细管、尖锐骨性结构和薄壁区域需额外观察局部误差。

### 8.2 平滑

Laplacian 基线采用：

\[
v_i'=v_i+\lambda\left(\frac{1}{|N(i)|}\sum_{j\in N(i)}v_j-v_i\right).
\]

它简单但可能收缩表面。Taubin 平滑每轮使用正、负系数的两步滤波，作为减少收缩的对照方法；仍需测量误差和可用时的体积变化。[Taubin, 1995](https://doi.org/10.1145/218380.218473)

建议用 0、5、10 次迭代作为起始候选；Taubin 系数先用选定库版本的默认值，再在开发集调整。不要把同迭代次数当成等计算量，报告实际时间。

若模型带天然开口，固定边界顶点或只平滑明确指定内部区域。现成过滤器不支持所需固定策略时，第一版可自主实现均匀 Laplacian 并冻结边界，或关闭该样本的平滑。不能忽略开口变化。

### 8.3 重划分

使用各向同性重划分，调整边长和三角形形状。操作可能增加面数，因此评价目标是质量分布与表面保持，而非「重划分一定压缩模型」。

第一版保留：

- 用户可设目标边长与少量迭代。
- 边界和特征保护配置。
- 输出面数、质量、边长分布与表面偏差。
- 对原形状的最终复检。

使用中位边长的 0.8、1.0、1.2 倍作为独立实验起点。根据实际过滤器参数明确传入绝对长度或百分比包装值，不能把 1 mm 当作 1%。[重划分接口](https://pymeshlab.readthedocs.io/en/latest/filter_list.html#meshing-isotropic-explicit-remeshing)

### 8.4 误差约束候选搜索

优化参考为**已经复检通过或已明确接受的修复模型**，不是损坏输入。所有候选都从同一参考重新生成，避免逐级处理造成累计误差和不同起点。

基本候选集合为：

- QEM 保留率：0.8、0.5、0.3。
- Taubin 迭代：0、5、10。
- 共 9 个候选，加原参考作为兜底。

重划分先作为独立功能与实验，不扩大到整个组合网格。扩展时最多增加 3 个候选，保持时间预算清楚。

接受条件：

1. 没有新增非法坐标、退化面、非流形或方向冲突。
2. 原有天然开口和预期连通分量保留。
3. 已经闭合且验证过的参考没有变成开放模型。
4. 双向表面误差符合用户定义的界限。
5. 局部保护区域的误差符合界限。
6. 面积、可用时的体积变化在配置范围内。
7. 检查所需结果全部存在；缺失或检测失败不能当作通过。

在合格候选中先选实际面数最少的，面数相同再选误差较小的，最后比较耗时。若无合格候选，返回参考模型并标记 no_candidate_accepted。

### 8.5 建议起始约束

以下仅用于课程实验调试，之后在开发集冻结：

| 指标 | 起始值示例 | 解释 |
|---|---:|---|
| 双向 D95/D | ≤0.001 | 95% 分位的尺度归一化偏差 |
| 双向采样最大偏差/D | ≤0.003 | 辅助防止局部大变化，依赖采样密度 |
| 面积相对变化 | ≤1% | 平滑/简化的辅助约束 |
| 体积相对变化 | ≤1% | 仅对两者均有效闭合的模型 |
| 分量数 | 与参考一致 | 不自动合并或删除解剖结构 |
| 目标开口 | 保持对应关系 | 不仅检查环数量，还检查位置与形状 |

D 是优化参考的包围盒对角线。D95 可能掩盖很小区域中的大误差，因此必须同时看采样最大值、局部 ROI 与误差色图。大器官的归一化阈值也可能对细血管过宽，不能宣称是医学精度标准。

### 8.6 计划接口伪代码

~~~python
def choose_candidate(reference, configs, limits):
    results = []
    for config in configs:
        candidate = run_from_reference_copy(reference, config)
        diagnosis = diagnose(candidate)
        metrics = compare_surfaces(reference, candidate)
        accepted, reasons = check_all_constraints(
            reference, candidate, diagnosis, metrics, limits)
        results.append((candidate, config, metrics, accepted, reasons))
    valid = [r for r in results if r[3]]
    if not valid:
        return reference, results, "no_candidate_accepted"
    best = min(valid, key=lambda r: (
        len(r[0].faces), r[2]["d95"], r[2]["elapsed_seconds"]))
    return best[0], results, "accepted"
~~~

这是待实现的项目接口，不是可直接运行的完整程序。所有尝试的计算时间都计入方法总耗时，包括拒绝的候选；不能只报告最后获选候选的时间。

## 9. 误差计算、质量指标与结果解释

### 9.1 点到表面，而非只比较顶点

比较两个模型时在其三角表面按面积采样，查询采样点到对方三角表面的最短距离。只用 KD-tree 查最近顶点，会受到网格密度影响，不能作为主要几何精度指标。

推荐用 VTK 的 cell locator 查询最近单元上的点。返回的是到单元表面的距离，不限定最近顶点；Python 接口和并发方式以所用版本确认。[VTK 最近表面查询](https://vtk.org/doc/nightly/html/classvtkStaticCellLocator.html)

若性能不足，可选 Open3D RaycastingScene 等经过验证的点到表面实现；保持相同采样与评价口径。退回点到点指标时，必须明确标记为辅助近似。

### 9.2 面积均匀采样

1. 计算各三角面面积，过滤零面积。
2. 按面面积占比随机选择三角面。
3. 令 u、v∈[0,1]，s=√u。
4. 采样点为 (1-s)v0+s(1-v)v1+s v v2。

候选评估先用每方向约 10,000 个点，最终评价使用约 50,000 个点，并做 10k/50k/100k 的稳定性实验。实际点数根据运行时间确定。

同一参考使用固定随机种子的参考采样点。输出侧按各输出的面积独立采样。新增补洞区域、尖锐结构和保护 ROI 另外加密，单独报告局部误差；不能为了让整体误差看起来好而删掉局部样本。

### 9.3 指标定义

设参考为 A、处理结果为 B；d(A→B) 和 d(B→A) 是两方向采样点到表面的距离集合。

**双向平均表面距离：**

\[
ASD=\frac12\left(\operatorname{mean}d(A\to B)+
\operatorname{mean}d(B\to A)\right).
\]

**双向 95% 分位偏差：**

\[
D_{95}=\max\{Q_{0.95}(d(A\to B)),Q_{0.95}(d(B\to A))\}.
\]

**双向采样最大偏差：**

\[
D_{\max,sample}=\max\{\max d(A\to B),\max d(B\to A)\}.
\]

第三项是有限采样估计，报告为「采样最大偏差」或「近似 Hausdorff」，不标为精确 Hausdorff。全文沿用同一定义，不混用双向合并分位与方向分位最大值。

**面数削减率：**

\[
R_f=1-\frac{M_B}{M_A}.
\]

**面积/体积相对变化：**

\[
\Delta S=\frac{|S_B-S_A|}{S_A},\quad
\Delta V=\frac{|V_B-V_A|}{|V_A|}.
\]

面积或体积分母为零或不可用时输出 unavailable 与原因，不用零表示。体积只在两者都通过相应闭合、方向及自交检查时比较。

### 9.4 三角形质量

使用尺度不变质量：

\[
q=\frac{4\sqrt3 A}{l_1^2+l_2^2+l_3^2},
\quad 0\le q\le1.
\]

等边三角形 q=1，退化三角形趋近 0。报告最小值、P5、中位数和低质量面比例；低质量门槛如 q<0.1 只作为实验配置，不是制造或 FEA 通用标准。

可补充最小角分布、边长变异系数、边界环数、连通分量数、面方向冲突数。重划分后质量改善与形状偏差必须同时呈现。

### 9.5 三种参考关系必须分开

| 场景 | 参考对象 | 能说明什么 |
|---|---|---|
| 合成损坏修复 | 未损坏且检查过的原模型 | 对这类人工缺陷的几何恢复表现 |
| 真实模型修复 | 输入的未修改区域和专家指定目标 | 处理引入的变化；没有真值时不证明补洞真实解剖 |
| 网格优化 | 修复后接受的参考模型 | 优化阶段新增的几何与拓扑变化 |

优化参数选择不能使用合成实验的隐藏未损坏真值，否则方法获得了部署时不存在的信息。隐藏真值只用于最终实验评价。

### 9.6 色图与报告

同时展示参考→结果和结果→参考的误差；所有对照方法使用相同单位与色标范围。若色标裁剪，报告上限和超过上限的比例。不得每张图自动拉伸色标后比较颜色深浅。

每份报告写：模型来源、单位状态、参考对象、采样数/种子、距离实现、参数、拓扑检查状态、形状变化、总时间和失败项。

## 10. STL、STEP、IGS 转换及工程适配

### 10.1 六条转换路径

| 路径 | 实现 | 输出类型与限制 |
|---|---|---|
| STL→STEP | 网格转换为面片形状；缝合；满足条件时构造实体；导出 | 多面片 CAD 壳体或实体，不恢复建模历史 |
| STL→IGS | 网格转 CAD 面片后导出 IGES | 曲面集合/壳体为主，实际类型回读确认 |
| STEP→STL | 读取 CAD，按给定离散参数生成三角网格 | 曲面离散误差与网格质量需测量 |
| IGS→STL | 读取曲面/壳体并离散 | 开放几何可能得到开放网格 |
| STEP→IGS | CAD 形状读入后导出 IGES | 核对曲面、拓扑、单位与导出限制 |
| IGS→STEP | 读入 CAD 面片/曲面，再导出 STEP | 不凭格式变化推断实体有效 |

STEP/IGS 是 CAD 输入时，直接通过 CAD 内核交换，避免先 STL 化造成不必要精度损失。

### 10.2 FreeCAD 工作进程

推荐安装官方稳定 FreeCAD，记录版本与构建信息；使用它自带的 Python 或命令行运行器。不要假设普通虚拟环境执行 import FreeCAD 一定可用。

第一周查找实际运行器，使用官方安装目录或用户配置的绝对路径。不同平台路径不同，不在程序中只写死某个 macOS/Windows 路径。

任务文件示例：

~~~json
{
  "job_id": "cad_case_001",
  "input": "/absolute/path/input.stl",
  "output": "/absolute/path/output.step",
  "source_format": "stl",
  "target_format": "step",
  "requested_representation": "solid_if_valid",
  "unit_status": "confirmed",
  "unit_to_mm": 1.0,
  "sewing_tolerance_mm": 0.01,
  "linear_deflection_mm": 0.05,
  "angular_deflection_rad": 0.2,
  "timeout_seconds": 120
}
~~~

数值为示例，须根据确认单位和模型尺度调整。公差、离散参数不能直接当作已达到的几何精度。

### 10.3 网格→CAD 的执行步骤

1. 检查面数、单位和几何质量。
2. 若超出转换面数上限，要求提供经过独立误差检查的低面数副本。
3. 在 FreeCAD 环境创建 Mesh 与 Part Shape。
4. 用 makeShapeFromMesh 生成面片形状。
5. 判断壳体是否闭合、形状是否有效，再考虑构造 Solid。
6. 无效实体不继续标为有效实体；开放网格可按允许范围输出曲面/壳体。
7. 调用对应 STEP/IGES 导出接口。
8. 在新任务中重新读取导出的文件并检查。
9. 离散回网格，验证位置、尺寸、面片数量、几何类型和双向偏差。
10. 将原始网格→低面数副本的误差与副本→CAD 回读的误差分开记录；最终再比较原始网格与回读结果。

参考接口示意：

~~~python
# 仅在 FreeCAD 的 Python 环境运行。
# 此示例展示核心 API，不包含单位、异常、规模限制和完整校验。
import Mesh
import Part

mesh = Mesh.Mesh(input_stl)
shape = Part.Shape()
shape.makeShapeFromMesh(mesh.Topology, sewing_tolerance)
if not shape.isValid():
    raise RuntimeError("invalid CAD shape")
if shape.isClosed():
    solid = Part.makeSolid(shape)
    if solid.isValid():
        shape = solid
if target_format == "step":
    shape.exportStep(output_file)
elif target_format in ("igs", "iges"):
    shape.exportIges(output_file)
else:
    raise ValueError("unsupported CAD output")
~~~

FreeCAD 旧文档仓库已归档；上述思路由官方旧文档与当前源码相互核对。实际运行版本必须首周验证，不将网页上的示例视为已通过的平台兼容性测试。

### 10.4 CAD→网格

读取形状后通过 MeshPart.meshFromShape 或经核实的等效接口离散。记录线性与角度离散参数、实际三角面数与输出边界。

对自生成球、圆柱等解析几何，可以计算采样点到解析曲面的偏差，作为更独立的验证。医学网格导出的 CAD 则以原网格作为几何参考。

不能只与同一粗糙离散结果比较而得出「精度极高」。用于回读验证的离散应比评价容差更细，并做至少两档离散参数的稳定性检查。

### 10.5 单位与坐标检查

- STL 坐标不自带可靠的单位约定；用户明确单位后按比例转换。
- CAD 内核通常按自己的标准单位表达，必须确认实际读写行为。
- 不仅比较包围盒长度，还比较中心位置、轴向和对应点偏差。
- 不能在回读后用 ICP、自动缩放或重新居中来隐藏转换错误。
- 测试一个非原点模型及一个已知非对称模型，防止平移、旋转和镜像错误漏检。

### 10.6 下游工程适配

基础验收用独立回读任务检查文件与几何。若有 NX 授权与环境，额外记录 NX 版本及导入截图。

无 NX 时用 FreeCAD 的新会话确认可读性，另可用 Gmsh 的 STEP/IGES 导入与表面网格生成功能作下游适配实验。Gmsh 官方说明其通过 OpenCASCADE 导入 STEP/IGES。[官方手册](https://gmsh.info/doc/texinfo/)

同内核回读主要验证文件往返；Gmsh 适配是下游工作流验证，仍不等于所有软件独立兼容。表面网格生成成功也不等于体网格或有限元求解准备完成。报告用「在指定工具与版本验证通过」，不用「所有工程软件无缝兼容」。

## 12. 实验设计与统计分析

### 12.1 实验 E1：检测正确性

使用人工几何与已知损坏样本，逐项核对重复面、退化面、指定非流形边/顶点和简单边界环。自交采用独立已知例子。

检测评价在清理前开展，保持索引与构造记录。面重编号后需要映射或几何标识，不能拿旧面 ID 直接计算精确率。

报告确定性单元样本的预期值与实测值；对医学损坏样本记录缺陷实例检出、误报和定位。边界环本来存在时纳入 expected_open_boundaries，不把它算成误检缺洞。

### 12.2 实验 E2：修复与结构保护

至少三组：

- B0：不修复，仅诊断。
- B1：固定参数流程。
- B2：本系统的目标保护、复检和回退流程。
- B3：可选 PyMeshFix，仅用于其假设匹配的单个闭合样本。

记录：残留缺陷、是否新增缺陷、开口/分量保留、对隐藏参考的整体和局部偏差、时间。不能把 B2 拒绝处理的样本删除；它们进入成功/拒绝率和失败分析。

闭合样本的成功判定要求目标缺陷消除、完整质量检查通过、几何变化满足预先定义条件。开放样本则要求指定开口仍保留，不以闭合性为目标。

### 12.3 实验 E3：简化与平滑

简化保留率可取 80%、50%、30%、10%，其中 10% 作为压力测试，不一定接受。

对照未平滑、Laplacian、Taubin。分别画：

- 实际面数保留率—D95。
- 面数—采样最大偏差。
- 迭代次数—体积变化（只对可用模型）。
- 总耗时—面数削减。
- 有开口/细结构模型的局部误差图。

固定参数方法与候选搜索必须使用相同库版本和评价指标。候选搜索的总开销单独展示，避免把多次尝试带来的收益包装成同成本优势。

### 12.4 实验 E4：重划分

比较处理前后 q 分布、低质量面比例、边长变异系数、面数、双向误差和时间。目标是「质量改善与形状保持的权衡」，不要求所有模型所有指标都改善。

若改善质量同时显著增加面数，报告这项代价；不要只展示较好的 q 中位数。

### 12.5 实验 E5：误差约束搜索与消融

比较：

| 方法 | 候选搜索 | 几何约束 | 拓扑/开口保护 |
|---|---|---|---|
| 固定参数 | 否 | 事后测量 | 基础库选项 |
| 搜索但无几何约束 | 是 | 否 | 有 |
| 搜索但无拓扑保护 | 是 | 有 | 否，限合成实验副本 |
| 完整方法 | 是 | 有 | 有 |

观察面数、误差、拒绝率、开口破坏与总时间。消融组只在实验副本运行。必须如实报告完整方法在简单模型上可能没有额外收益。

再做一次评价采样密度消融，检验 10k 点是否漏掉局部尖峰误差。

### 12.6 实验 E6：六方向转换

对 4 个自生成 CAD/网格模型执行全部方向，覆盖闭合、开放、非原点和非对称几何；再对至少 3 个医学低面数副本验证 STL→STEP/IGS 和返回网格。

记录六条路径各自的尝试数、成功数、拒绝数和失败数。闭合 STL 必须检查输出实体/壳体；开放 STL 的曲面输出是预期类型，不能混成实体成功。

CAD 变体测试建议为 1k、3k、5k 三个面数档；最高档只作为性能与稳定性探索，面数上限由首周验证决定。

### 12.7 汇总单位与统计

每个原始模型先汇总其变体，再报告不同原模型之间的中位数、四分位范围和逐模型结果。若需要置信区间，按原模型组重采样，不能按所有损坏副本独立 bootstrap。

样本较小不强行做显著性宣称。优先展示效应大小、失败类型和一致性。没有运行的实验写「待运行」，不预填看起来漂亮的结果。

## 13. 环境安装与首周可行性验证

### 13.1 环境原则

推荐 Python 3.11 或 3.12 的独立虚拟环境，先选择一个平台完成；确认所选版本在目标平台有需要的二进制包。不要从课程开始就同时承担 Windows、macOS 和 Linux 的完整打包。

### 13.5 最小算法调用示例

下面示例只展示过滤器调用路线，需在锁定环境验证，不包含正式的目标边界保护、单位与复检。不要直接作为完整修复程序提交。

~~~python
import pymeshlab

ms = pymeshlab.MeshSet()
ms.load_new_mesh("input.stl")
ms.apply_filter("meshing_remove_duplicate_faces")
ms.apply_filter("meshing_remove_null_faces")
ms.apply_filter("meshing_remove_unreferenced_vertices")
ms.apply_filter("meshing_re_orient_faces_coherently")
ms.apply_filter(
    "meshing_decimation_quadric_edge_collapse",
    targetfacenum=3000,
    preserveboundary=True,
    preservenormal=True,
    preservetopology=True,
)
ms.save_current_mesh("simplified.stl")
~~~

正式程序需将每步输入输出、参数与检查结果写入任务目录。若加载器已自动处理顶点，需记录其行为，不能直接用该结果代替原始缺陷检测。

每周开始选 3–5 个可验证小任务，每个任务尽量在半天到一天形成结果。周末只看实际输出和验证记录，不用「代码写了多少」判断完成。

### 14.3 两人分工

- A：拓扑检测、修复、数据构造、算法测试。
- B：界面、评价、CAD 转换、报告与实验自动化。

### 14.4 优先级

## 15. 测试清单与最终验收标准

### 15.1 必须有的确定性测试

| 编号 | 测试模型/场景 | 预期行为 |
|---|---|---|
| T01 | 完整闭合四面体 | 无边界，边度数正常，闭合检查通过 |
| T02 | 四面体删一面 | 形成一个三边环；受控补洞后复检 |
| T03 | 重复及反向重复面 | 数量正确；清理后统计恢复 |
| T04 | 共线/重复索引三角形 | 正确标为退化，不污染正常边表 |
| T05 | 一条边关联三个面 | 非流形边被定位 |
| T06 | 两个闭合组件只共用一点 | 顶点非流形被发现，不能仅因边度数正常就通过 |
| T07 | 局部面翻向 | 方向冲突被发现并复检 |
| T08 | 开放管段 | 两端开口保留，默认不补洞 |
| T09 | 两个独立模型 | 默认保留两分量，不能自动只留最大块 |
| T10 | 已知自交三角片 | 检测或明确未验证，不能报告零缺陷 |
| T11 | NaN/非法索引/空文件 | 明确失败，GUI 可继续操作 |
| T12 | 完全相同的两个模型 | 双向表面距离接近数值零 |
| T13 | 球/平面等可解析几何 | 距离实现与解析值相符 |
| T14 | 明确超差候选 | 拒绝并回退，而非自动放宽门槛 |
| T15 | CAD 六方向及非原点非对称模型 | 类型、位置、尺寸与回读偏差正确 |
| T16 | 取消/超时/工作进程异常 | GUI 恢复，原模型及日志保留 |
| T17 | 单位按已知比例变化 | 导出尺寸符合预期，单位状态明确 |
| T18 | 保存后重新读取 STL | 因顶点重复导致的统计差异被规范化处理 |

这些测试验证实际失效场景，不只检查某个函数是否返回对象。

### 15.2 定量验收如何定

- 拓扑单元样本：按构造的已知结果逐项准确核对。
- 基础修复：定义范围内样本经过修复与完整复检；天然开口与分量不误删。
- 优化：被接受的候选符合已冻结的评价口径；最终独立高密度评价超差时标记失败或重新保守选择，不能只相信低密度候选评分。
- 六方向转换：自生成标准样本逐条验证；医学模型报告各条路径的实际尝试、成功、拒绝与失败。
- 实验：完整保留每个原模型和方法的结果，包括拒绝与失败。
- 复现：在干净环境按 README 可运行至少三条完整流程。

成功率目标应在首周可行性实验后、最终测试前冻结。不能运行后选择一个刚好覆盖结果的门槛。

### 15.3 性能测量

记录硬件、面数、采样点数和任务耗时。至少测 1 万、5 万、10 万面三个网格档，以及 CAD 转换允许档。超出档位作为压力测试。

分别报告：读取、诊断、修复、候选搜索、评价、CAD 转换和总耗时。GUI 交互使用显示副本时标记面数。不要混用显示帧率和计算速度。

### 15.4 结果真实性检查

提交前确认：

- 未运行实验没有填入数值。
- unavailable、rejected、failed 不转换成零误差或成功。
- 统计分母包括应计入的失败样本。
- 实验阈值、原模型分组和基线在测试前固定。
- 输出模型来自记录的参数与版本。
- 同源损坏副本没有被称为独立患者样本。
- 误差图色标和单位一致。

## 16. 风险、替代方案与范围控制

| 风险 | 预防 | 替代/处理 | 对交付的影响 |
|---|---|---|---|
| CAD 转换耗时或无效 | 首周即做六路径；限制面数；先修复 | 保留壳体/曲面类型，闭合实体仅在有效时输出；失败明示 | 不承诺任意面数或任意坏模型 |
| Qt 动态库冲突 | GUI、网格、CAD 分进程 | 固定依赖、清理跨环境插件变量、外部运行器 | 可能增加环境调试时间 |
| 误封天然开口 | 边界角色与选择区域 | 只修选定环；未知边界保留 | 完整功能无需强制所有模型闭合 |
| 非流形修复删错结构 | 候选修复、快照、复检 | 拆分策略与删除策略分别比较，失败回退 | 报告部分修复，不能伪装成功 |
| 医学模型来源/许可不明 | 首周检查 manifest | 更换数据；先用自生成模型推进核心技术 | 缩小解剖样本覆盖并如实说明 |
| 距离评价慢 | 先建 locator，分级采样 | 批处理、独立进程；可选更快点到表面后端 | 不用最近顶点假装高精度 |
| 过度平滑/简化 | 全局与局部误差约束 | 降低处理强度或保留参考模型 | 允许零削减，不放宽门槛掩盖 |
| 高面数自交检测慢 | 规模限制与超时 | 明确未验证，降低副本规模后另测 | 未验证结果不能标为闭合有效 |
| 最后才写报告 | 周周保存日志与图表 | 使用固定报告模板与实验脚本 | 减少答辩前补材料风险 |

核心技术有成熟实现，因此方案具有工程可实施基础；保证可实施的方法是先通过首周 Gate，再按周完成证据与验收。文档本身不能替代目标平台的实际运行结果。

### 17.4 应能回答的问题

| 问题 | 回答应包含 |

| 为什么不能只比较最近顶点？ | 结果受采样密度影响，应点到三角表面 |
| QEM 的代价是什么？ | 对相邻平面的二次距离累计及边折叠 |
| Taubin 一定保体积吗？ | 不保证，本实验测量形状和体积变化 |
| STL 转 STEP 是否变成参数化模型？ | 面片 CAD 不恢复草图或历史；实体有效性另行检查 |
| 创新在哪里？ | 自主检测、目标保护、受约束候选选择、可复现实验与失败分析 |
| 有没有证明临床准确？ | 证明的是定义样本上的几何处理表现，不将其扩大为临床结论 |

### 17.5 可争取的评分证据

围绕需求完成度、算法理解、实验严谨性、工程可靠性、报告清晰度和自主贡献准备材料。不要为了「看起来更高级」加入未经验证的 AI 标题或宣称新的医学诊断能力。
