## 1. 答辩时如何启动

双击工程中的 **启动髌骨答辩演示.command**。该入口直接打开“课设演示”页和“答辩演示总览”，所有操作在一个Qt窗口中完成。

命令行等价入口：

```bash

```

原来的`启动医学网格工作台.command`也可使用，进入后选择左侧第四个页签“课设演示”。

## 2. 两种操作必须区分

### 一键重新运行完整实验

点击“一键重新运行完整实验”，后台实际执行以下五个阶段：

1. **来源与模型**：读取缓存或下载官方SPL Knee Atlas，核对ZIP与髌骨VTK的固定SHA256，展开三角带，规范化完全相同坐标的索引，并保存来源与许可。
2. **优化及种子复核**：运行十组配置，包括身份基线、六档QEM、Laplacian、Taubin和QEM+Taubin；筛选每方向10,000点、最终复核50,000点，并对符合条件的候选追加三组独立种子，保持原阈值后再选型。
3. **六向转换回读**：依次运行STL→STEP、STL→IGS、STEP→STL、STEP→IGS、IGS→STL、IGS→STEP。每项真实写出、新进程细/粗两档回读、双向误差检查，再相对于原始MRI模型计算端到端误差。
4. **负对照**：平移、错误尺度和未知STL单位必须被正确拒绝。
5. **报告与审计**：新生成17节Markdown/HTML报告、五幅图、两张CSV及产物哈希审计。

任务使用新的时间戳和随机编号目录；不复用历史转换文件冒充新计算，不覆盖此前交付的报告。所选候选仍是`candidate_unaccepted / unverified`，当前工作模型的版本、坐标和哈希保持不变。

右侧进度条显示**已完成阶段数0～5**，不是剩余时间估计。十组优化结果与每个转换方向的实际步骤会持续更新；运行时可查看已经完成的优化对比和方向详情，也可点击窗口底部“取消任务”。整项默认15分钟超时，可调整。

### 载入所选历史实验

从历史列表选择一项，点击“载入所选历史实验”。界面明确显示 **历史记录查看 · 未重新计算**。这一操作只读取已有结果，适合时间较短、没有网络或不希望重复计算的答辩。

列表包含之前的`medical_patella_verified_20261022`，以及本窗口新生成的演示。失败和取消记录也会保留，加载后不会显示为成功。非默认保存目录记录在`runs/patella_demo_history.json`；也可以通过顶部“打开已有任务 / 报告”选择某个任务的`result.json`重新打开。

## 3. 一窗口展示路径

- **答辩演示总览**：五阶段状态、十组优化对照、选中候选、六方向写出/回读/几何状态，以及转换D95和端到端D95。
- **原始 / 优化模型对比**：左侧按钮切换双视图，相机同步；原始49,862面，最终研究候选2,400面。色图来自选中候选完整50,000点/方向的评价，显示点数为交互性能而降采样，指标不降采样。
- **选中方向的回读模型 / 指标**：在总览选择方向行，点击下方按钮，查看该方向真实回读模型、实际Shell/Compound/网格表示、单位、阈值与检查。
- **选中方向的详细报告**：在本窗口阅读该方向HTML与完整JSON，包含原始→最终、候选→完整来源链两类补充指标。
- **本次实验总报告**：左侧“查看本次实验总报告”或底部“窗口内查看报告”，直接进入内置报告页，无需外部浏览器。

左侧控制区可滚动；底部全局报告入口始终可用。六个方向在总览中可同时看到，优化表格可以滚动查看其余配置。

## 4. 建议答辩讲述顺序

1. 说明来源为公开MRI重建髌骨，展示来源、许可和固定哈希。
2. 点击真实重新运行，解释“五阶段”与六个方向中的写出、回读、几何是独立状态。
3. 观察1,798面方案虽然单次复核通过，却被追加种子淘汰；最终2,400面减面约95.19%、优化D95约0.03059mm，说明阈值控制而非单纯追求最少面。
4. 展示原始/优化模型，再选择一个STEP或IGS回读方向查看实际类型。
5. 强调转换D95与相对于原始MRI的端到端D95不同。面片CAD的近零转换数值不是MRI解剖精度，也不是原生参数CAD兼容性证明。
6. 打开本次新报告，展示失败对照、三个种子及数据许可。根据时间决定是否实际再运行；历史查看要明确说明未重算。

本机默认答辩记录模式本次实测约63.7秒，使用已有源缓存；完整采样模式本次约68.8秒。时间受电脑、磁盘和首次库加载影响，不能把这一数值当作保证。首次缺少缓存需下载约77MiB。

## 5. 存储模式与空间检查

默认“答辩记录模式”保留：全部模型、请求、日志、指标、种子、图表、选中优化候选完整采样，以及六次转换回读的完整采样。未选优化方案、追加种子和端到端评价不保存重复采样数组；这些评价仍实际计算完整50,000点/方向。

勾选“保留所有中间采样”可保存所有这些数组。实际策略写入每次任务的`storage_policy.json`，并在新报告第14节说明；没有用少量采样替代最终评价。

本机本次答辩记录约81MiB，完整记录约289MiB。界面与后台都做空间预检：默认至少160MiB空余，完整模式至少512MiB；缓存缺失在相同磁盘时另留100MiB下载空间。可使用“保存位置”选择其他目录或外接磁盘，源缓存磁盘也会单独检查。

附加回归中实际遇到过系统磁盘不足；没有清理用户文件，也没有删改原医学实验。随后空间恢复，重新执行了回归并通过。另用模拟0可用空间验证了界面在提交前阻止任务，避免伪成功。若运行过程中磁盘再次耗尽，日志写入错误会停止当前任务、解除忙碌状态并显示错误；若磁盘完全不可写，不能保证失败报告能落盘。

## 7. 实现与边界

- `src/medical_mesh/experiments/patella.py`：原实验代码共享为库，CLI入口仍兼容。
- `experiments/demo.py`：后台五阶段编排、空间检查、最终状态与独立输出目录。
- `experiments/patella_report.py`：新报告生成与审计；演示调用`publish=False`，不覆盖之前交付副本。
- `jobs/worker.py`、`jobs/qt_manager.py`：`patella_demo`任务、结构化进度、取消进程组、保留详细报告。
- `ui/patella_demo.py`、`ui/main_window.py`：单击入口、总览、历史与查看动作。
- `启动髌骨答辩演示.command`：答辩专用启动器。

仍是一个公开MRI图谱表面的课程实验。成员1完整结构诊断、非流形顶点/自交/ROI、正式版本提交、实体资格和其他CAD厂商兼容性未被冒充完成。
