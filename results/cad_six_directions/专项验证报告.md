# STEP / IGS / STL 六向转换专项验证

本机 Windows 实测已完成；E-3D 当前可访问入口未找到等效 STEP/IGS 转换功能，因此没有可报告的厂商六向输出或胜负结论。

## 本项目实际结果

- 环境：项目内便携 FreeCAD 1.1.4、OpenCASCADE 7.8.1。官方下载和 SHA-256 记录见 [来源校验](runtime_download_manifest.json)。
- 六向：STL→STEP、STL→IGS、STEP→STL、IGS→STL、STEP→IGS、IGS→STEP。
- 平移方盒、球面、开放平面、不对称几何，4×6＝24 项全部通过。真实写出后由新进程两档回读，每方向50,000采样点，无ICP、居中或自动缩放。
- 24项最大D95为 0.016316 mm；最大包围盒坐标偏差 0.014695 mm。采样距离不是严格最大距离。
- 8项异常验证全部通过：未知STL单位、面数预算、未获准实体模式、非法离散参数、同格式、超时、损坏STEP、退化周期IGES。厘米→毫米10倍转换通过。
- 统一工作台真实按钮验证六方向全部通过；UI保持响应，转换不会替换正式模型。完整回归测试145项通过，无跳过。

## E-3D 对照边界

已实际查看本机登录试用版V24.09应用菜单、STL导入文件类型、CAD工具栏，并结合此前真实网格导出窗口核对。菜单列出网格/影像导入，STL筛选器为STL及所有文件；CAD栏是草图、基础几何、拉伸旋转、偏移抽壳及布尔等建模工具，未发现STEP/IGS格式转换入口。此前网格导出格式列表只有STL、OBJ、PLY。

“所有文件”筛选不是STEP/IGS解析支持证据。没有在错误的STL导入器中强行导入CAD并把报错当作E-3D能力结论，也没有伪造厂商导出。

## 使用和复现

重新启动“启动医学三维工作台.cmd”，进入“格式与导出”，选择外部STL/STEP/IGS或当前网格，选择目标格式，确认STL单位，点击“转换并回读验证”。当前网格超过3000面须先简化。STL转CAD按面片曲面处理，不恢复光滑参数曲面或建模历史，不宣称输出合格实体。

便携环境仅保存在本项目tools/freecad内，不修改系统安装；交付包不包含该大体积第三方环境。新机器联网运行 `python scripts/setup_freecad_portable.py` 下载并校验后生成本地配置。复测命令：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/validate_cad.py --out results/cad_six_directions/new_run --config configs/freecad.local.json
.\.venv\Scripts\python.exe -X utf8 scripts/verify_cad_workflow.py
```

本轮为四类合成几何和同一OpenCASCADE内核回读验证，不代表临床验证、所有医学模型、其他CAD软件或大面数曲面重建均已验证。
